# Wild 与 Life 的接口边界

本轮 City 发展弧属于独立 Wild 游戏。启动、保存、经营、科研与托卡马克之冠均不依赖现实任务系统；没有连接其他仓库、账户或真实记录。

将来 Life 桥接采用显式确认的事实消息，至少包含协议版本、来源实例、稳定事实 ID、事实修订号、发生时间、确认状态和映射版本。去重键为来源实例 + 事实 ID + 修订号；重传不能再次发放 DT、许可或资源。事实更正另记修订，保留原确认与映射来源，不静默改写已经发生的城市历史。

现实事实与城市奖励分开保存。待确认事实不自动产生游戏收益；已确认事实也须经过当时明确采用的映射规则。版本变化不追溯重领旧奖励。删除或更正事实时，由后续明确决定的补偿规则处理，不把真实记录直接当作可修改的钱包。

此处只定义接口责任。本轮未实现现实端、传输服务、自动映射或真实用户数据验收。
