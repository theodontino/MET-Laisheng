# MET 0.4 美术资产管线

本批资源由 Blender 参数化几何、手工材质和柔光渲染制作，供二维地图以精灵方式组合。生成器为 [`tools/make_art040.py`](../../tools/make_art040.py)，目录和调用映射为 [`art_catalog.json`](../../content/presentation040/art_catalog.json)。

## 交付内容

- 21 栋建筑：包括全部定义节点，每栋均有独立轮廓；同一建筑的升级形态以层数、屋顶构造、立面和设备变化区分。T2 居住由三段高低楼翼围出绿化庭院，T3 为主塔、双侧翼和多层露台组合。
- 24 件共用装饰：树、灌木、岩石、座椅、路灯、围栏、摊位、箱料、材料堆、垄田、花丛；8 种模块；3 级山岩；1 处庭院。
- 共 45 张透明 PNG。建筑为 768×768；共用装饰、模块、山岩和庭院为 256×256。PNG 未烘焙地面接触阴影，由游戏绘制统一软阴影。
- 可编辑代表场景：[advanced_residence.blend](../../art_source/visual040/source_scenes/advanced_residence.blend)，包含模型、材质、正交相机和灯光。其余资源由同一脚本的参数化设计生成。
- [全部资产缩略图](../../art_source/visual040/visual040_contact_sheet.png)；[T1/T2/T3与树木放大预览](../../art_source/visual040/preview_civ6_round2.png)。

## 相机、尺度与渲染

相机朝向原点的向量为 **(9, -12, 13.2)**，方位角 **-53.1301°**、俯角约 **41.35°**，正交投影。地面投影压缩为 **0.661**，地形高度投影压缩为 **0.751**。建筑统一使用 64 世界单位画幅；共用小道具 20、模块 26、山岩 42、庭院 26 世界单位画幅。建筑模型使用相同相机尺度，保留各自实际占地和高度差。

地面锚点采用左上原点归一化坐标 **(0.50, 0.64)**：建筑像素坐标 **(384, 491.52)**，256px 资源为 **(128, 163.84)**。目录中的 `bounds` 是 PNG alpha 的左上原点边界，`world_bounds` 是场景几何世界坐标边界；`pixels_per_world_unit` 记录相机尺度下的像素密度。

使用 Blender **4.5.1 LTS / EEVEE Next**、32 个渲染采样。暖色方向日光从屏幕左上投射，并以大面积柔光和宽柔正面补光控制阴影；标准色彩管理与低曝光补偿保留明暗层次。调色采用日照赭黄色墙面、鲜明陶土屋瓦、蓝绿色玻璃与金属，以及由深到亮的分层叶色，提升地图缩放时的色块辨识度。

## 生成与映射

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/make_art040.py -- --all
python3 tools/make_art040.py -- --contact
```

`assets` 保存资源路径、像素尺寸、接地点、alpha 边界和世界包围盒。`bindings` 对全部建筑定义 ID 同时提供裸 ID 与 `building.<id>` 映射。`aliases` 保留旧建筑名 `hamlet/farm/timber/power/works/market/school/clinic/park/warehouse`，以及旧模块名 `storage/heat/recycle/open_court/reuse/roof_farm/drone/workshop`；模块工作坊资源 ID 为 `module_workshop`，建筑 `workshop` 由建筑 binding 指向 `building_workshop`。其他环境和装饰以自身 ID 提供，并在 `aliases` 中提供对应旧调用名。

## 验证

本批 45 张均通过 Blender 实际出图。逐张确认 PNG 存在、RGBA 尺寸与目录一致、alpha 同时含透明和不透明像素，alpha 内容不触及最外 2px；21 个建筑定义均有资产及双格式 binding。代表 `.blend` 场景为可编辑源文件，不进入运行时资产目录。
