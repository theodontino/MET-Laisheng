# 后续展望

以下内容不属于当前 0.4 pre-alpha，也没有菜单入口或保存状态占位。

- District：管理多个已完成的 Block，而不只是当前一张地图。
- Block 移交与遗产：由玩家决定何时结束经营，并选择少量已获得方案作为下一地区的启动资产。
- 永久制度：极少数 District 级方案跨地图生效，与一次部署许可分别设计。
- 地区级市场与更完整的贸易网络：当前市场只属于单一 Block，不模拟其他城市或实时物流。

等单 Block 的建筑升级、施工能力、委托奖励和贸易体验稳定后，再确定上述功能的实际范围。整个 pre-alpha 阶段不承担跨版本存档兼容；正式稳定存档协议另行制定。

开发过程中已经编写的 District 原型保存在 `../archive040/district040.gd.txt`，仅供后续参考，当前游戏不加载。
