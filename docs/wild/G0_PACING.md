# MET Wild G0：现有游戏工程节奏基线

2026-10-26。范围仅为 G0：用当前 Unity 原生 Core 建立可重复的最小场景，观测 12 分钟等效经营。没有新增 Wild 机制、改数值、注入资源、加快施工、自动领奖或代替玩家判断。此页的工程通过不代表真人已经接受节奏、选择意义或乐趣。

## 重现

在仓库根目录执行：

```sh
DOTNET_ROOT="$PWD/.toolcache/dotnet" \
DOTNET_CLI_HOME="$PWD/.toolcache/dotnet-home" \
NUGET_PACKAGES="$PWD/.toolcache/nuget" \
.toolcache/dotnet/dotnet run \
  --project tools/unity_core/WildG0.Checks.csproj \
  -p:UseSharedCompilation=false -p:NuGetAudit=false \
  -- content build/wild-g0
```

输出均隔离在 `build/wild-g0/`：`initial/met_city_v1.json` 是**暂停的原始起点**，可交给当前 Player 的整城存档加载；`final/met_city_v1.json` 是工程回放终点；`roundtrip/met_city_v1.json` 用于保存恢复检查；`replay.json` 是输入配方；`evidence.json` 是机器可读结果。不接触用户的常用存档目录。该工具直接引用 `Met.Core.csproj`，没有运行 Unity、启动 Player 或伪造截图。

种子 `20261026`、UTC `0`、城市名 `MET Wild G0 工程基线`，通过现有 `CitySession.New`、`BeginDistrict(0,"balanced")` 开局，选实际提供的第一个起源，实测为 `free`。这是明确的测试输入，不能解释成产品默认起点或平衡建议。地图由现有 `Hex.make_map` 生成；初始两建筑、18 人、700 通货、75 DT、食物37/材料59/制成品0 全部来自现有开局规则。初始快照在任何预览、报价测试之前保存。
