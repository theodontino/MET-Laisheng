# MET Wild v0.1 · G0

当前只进入 G0：盘清现有 Unity 引擎、形成建筑构筑数据合同草案、建立当前游戏的可重复节奏基线，并提供独立 UI Toolkit 升级窗口试用。试用默认关闭，可从设置页主动开启；它使用现有 Beta 的真实升级规则，不代表 Wild 构筑机制已经实现。

- [引擎审计](G0_ENGINE_AUDIT.md)：命令、快照、建筑/Bonus、保存边界，以及可复用、需新增和本轮不触碰的范围。
- [数据合同草案](G0_DATA_CONTRACT.md)：字段与唯一数据 owner 映射；逐建筑设计容量、Tier 谱系、直建资格、槽构筑及设计模板的未来接入边界。
- [交付与运行记录](G0_DELIVERY.md)：实际 Player 截图、111 项工程检查、独立试玩入口及证据边界。
- [节奏基线](G0_PACING.md)：原生 Core 的 12 分钟等效确定性回放、33 项聚焦检查及待真人执行的观察脚本。

Q1–Q5 全部开放：撤销退款及依赖处理；全局 DP 与已有建筑容量成长；槽位指数成本范围和 Tier 重置；组织/联系/融合与槽型映射；高级形态首次取得时点。G0 不替用户决定这些问题，也不启动 G1 玩法实现。

已通过的 Core 工程检查不能证明 Unity 画面、真实鼠标键盘交互、性能或乐趣。Player 已构建并执行合成控件事件检查，详见交付记录。物理鼠标键盘、10–12 分钟真人游玩及体验反馈仍待用户验收。当前只以 2560×1440 桌面全屏为基线。
