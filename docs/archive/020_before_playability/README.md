## 0.2.0-b-buildlab.1 / 单一当前交付

**基于用户上传的 B 0.1.1 人口版原位重构，不是 C 版，也不是另一个 HTML 原型。**

游戏包：`MET B Build Lab.app`。源代码的入口仍是 `project.godot`，保留 B 的 Godot 主场景、Hex 地图、矢量建筑绘制、界面组件、存档外壳和源码历史。核心规则按新合同重构。

### 打开与存档

解压本次唯一 Mac 包，在本地打开 App。包内含 arm64 / x86_64 Godot 运行时，不需要再安装 Godot、Python 或模型。

**本次未在 macOS 实际启动。** Linux 同版本运行时执行了规则、完整流程和图形/鼠标测试；Mac 包只做了双架构、资源、代码页及临时签名的离线结构检查，不等于 Apple codesign / Gatekeeper 验证。本包没有 Developer ID 或公证。若 Mac 拦截、提示损坏或闪退，保留原始提示，不需要关闭全局安全保护或 SIP。

请新开一局。新版 schema3 使用独立目录 `MET-B-BuildLab-020`，文件 `b_buildlab_v3.json`。不读取、不覆盖 0.1.1 的 `MET-B-Population-v2`。旧人口版可继续保留。新旧数据结构变化大，不提供不可靠的旧存档转换。

### 第一轮怎么玩

**左侧选基础建筑 → 地图点一块陆地 → 发起招标 → 三份“运营商＋初始方案”选一份。**

不同候选的基础建筑、建造价格、额定参数相同。差别来自运营商的组织规则和初始 Bonus。你要农场，就一定建农场；不会被随机候选换成别的基本功能。

初始方案自动占用生产、物流或运营三槽中的一格。建好以后，点击建筑，在空槽征集方案；已占用槽可查看、替换或卸下。**运营商不是第四槽**，后续改装的方案提供方可以与建筑运营方不同。自营/外来方案会被相关规则读取。

每完成3个新项目，获得一次区域/组织方案机会。右上「Block / 政策」可以查看机会、获取不同尺度的 Bonus，或更换固定槽位中的政策。区域 Bonus 不占单栋建筑的槽。

下方「推进0.5 / 1 / 3 / 6h」消耗实际 DT，推进整个 Block 的生产、生活与施工。开局1100通货、42DT，加起源家底。不是所有候选都适合当前城市，不必把每格塞满。

### 这版主要看什么

- 工厂究竟缺劳力、物资还是能源？右栏区分建筑效率和运行率。
- 某张 Bonus 提高产出以后，多出的污染能不能成为另一栋建筑的回收原料？
- 工业余热是供给居民，还是回到工业节电？两者会争有限热量。
- 研究型医院、开放大学、邻里中心能否改变服务布置？转播不复制原始服务容量。
- 同一组织的建筑、以及该组织提供的改造方案，是否改变新方案的价值？
- 同一个槽只能装一种方案，换掉它之后整套结构会发生什么？

没有硬编码的“集齐三张套装奖励”。不要把首块Checklist完成当成好玩已经被证明。

### 看懂因果

点击建筑可看三槽、运营者/提供方、实际输入/产出、限制原因；「为什么是这个数」会列出基础值、规则来源和场来源。底部「来源与收支」看真实库存、分配和损耗。右上「居民 / 组织」看每个人群住在哪里、在谁那里工作、接受哪些服务。

人群独立于住宅：拆掉住宅后原居民仍存在，会重新安置或进入地图外待安置容器。1 Pop 最多分配1份工作；人员效率影响有效劳动，但不会让一个Pop被同时填进两份岗位。

### 操作

- 1：观察；2：选择地块；空格：推进1本地小时；Esc：返回地图。
- 滚轮缩放，中键拖动。道路作为建筑的自动连接，不需要手工铺设。
- F8：实验补给，会标记 `debug_used`；不能把用了补给的路线说成正常平衡。
- 右上「存档 / 设置 → 导出实测记录」会带出当前状态与日志，便于反馈卡点。

### 可玩内容与暂存内容

本次：**10种基础建筑、40个可生效Bonus、8个运营商、5个Policy槽/12个选项**。

Bonus文档中63个带编号候选全部有落实状态：40个进入运行池，23个保留待做。无编号的政策候选、未来多格/跨区想法仍完整保存在原设计文档。原 Bonus Pool 不是“每一项已经实现”的承诺。

单地块、单等级；没有恢复建筑升级树或旧Fusion按钮。通过装卸Bonus改变能力，不是偷偷恢复等级升级。没有多地块、公司财务、跨Block物流、定时Bonus、完整District/City或托卡马克之冠。

### 与0.1.1的刻意区别

本次是构筑实验，10种基础建筑直接可选，不再用人口/教育门槛把核心Bonus测试拖到后面。制成品库存只有实际生产后才显示；住户制造品消耗也从那时接入。完整渐进时代进程仍是后续工作。

人口不再使用65%劳动比例；维护是固定费用，不随低运行率自动减少。明确Bonus的维护修正仍可生效。污染和噪音在本版统一成环境负担；人口服务与就业共用“可达场＋有限容量分配”的基本思路。

### 开发

目标运行时：Godot 4.7.2 Standard。导入本目录的 `project.godot`。

```sh
# GODOT 指向你的4.7.2编辑器可执行文件
"$GODOT" --headless --path . -- --test
"$GODOT" --headless --path . -- --playthrough
"$GODOT" --path . -- --ui-smoke
"$GODOT" --headless --path . --export-release macOS build/MET_B_0.2.0_BuildLab_macOS.zip
```

有对应官方导出模板的编辑器可以正常导出。本次离线打包方式详见 `docs/PROVENANCE.md`，不要求后续继续复用模板App。

当前证据只看 `evidence020/` 和 `docs/TEST_REPORT.md`；原 `evidence/`、`evidence_B_original/`、`docs/archive/` 是历史，不混算本轮测试。
