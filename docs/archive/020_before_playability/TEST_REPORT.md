## 主要规则检查覆盖

- 人群独立于住宅、无65%比例、就业不能重复分配、拆住宅保留人群及就业来源。
- Field Source/Type分离；Tile实体可发场；负场不制造可回收正额度；Tile只缓存派生贡献。
- 可达性只决定资格/排序，不在成功就业后再次折损劳动力。
- 资源争抢不依赖申请字典遍历顺序；实际使用才扣预约收据。
- 默认能源不存储；显式storage.energy能力有限存储；工厂溢出先寻找仓储再记录损失。
- 单格、同底盘、运营商+初始Bonus、三槽、错误槽拒绝、互斥声明、Flex父子依赖。
- 局部/全Block/组织作用范围；Provider与Operator区分；同源改造覆盖；先天Trait不被改造Label篡改。
- 数字加减/乘/边界/Override顺序固定；具体规则优先；重复编译不累加污染结果。
- 资源和Field额度账平衡；热量有限预留并延迟一Tick回用；新建筑不在完工Tick追溯产出。
- 相同输入重复结果，JSON保存恢复后同引擎后续状态一致；损坏存档类型明确拒绝。
