## 过程中实际遇到的失败

- 最初两条宜居脚本失败：只看单体名义容量、机械选址，导致两片住区有一片没服务到；随后只会等待，人口继续增长。没有降低宜居阈值抹去失败，而是让公开路线使用真实选址预览并处理实际服务缺口，同时在目标页显示具体覆盖差距。早期4/6结果留在iterations/，不算最终通过。
- 发现住房满后每次小量出生都产生新待安置实体，已改为同来源合并，保留人数与就业关系，并补断言。
- 真实鼠标检查曾错误要求“DT余额一定下降”，被合法的首次粮食成果奖励打断；修改为消费账+奖励账对余额完整核算。旧失败记录保留，不宣称它当时通过。
- 组合执行最后一段鼠标调用曾超出工具时限；已单独重新执行完成，最终physical-input-harness.log才是本次依据。
- Xvfb有V-Sync不受驱动支持的警告，最终日志无脚本/解析错误；这是软件渲染环境，不是Mac性能证明。
