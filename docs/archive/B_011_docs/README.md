# MET B · 人口与生活
## 0.1.1-b-population — 从原 B 版继续迭代

本工程直接修改 B 0.1.0-exp003，保留原来的 Game / Simulation / Progress / Tenders / Storage 和 UI 分层。不是 C 分支移植，也不是第四套平行实现。

### 试玩

打开 `MET B Population.app`。包内已有 Godot 运行时，无需安装引擎、Python 或模型。

**请新开一局。** 新版将实际居民、教育、健康、就业写入 schema 2 存档，使用独立目录 `MET-B-Population-v2`。原 B 的 `MET-First-Block-EXP003` 不会被读取或覆盖，两个 App 可以分别保留。此版不提供旧存档数值转换；手工导入 schema 1 会明确拒绝。

推荐 1440×900；最低 1180×740。Mac 包含 arm64 / x86_64，但本次执行环境为 Linux；Mac 启动、触控板、Retina 和系统安全授权仍待个人实测。本包使用临时 ad-hoc 签名，没有 Developer ID 公证。遇到启动拦截、损坏提示或闪退，请保留原始提示，不要关闭全局安全保护。

### 开局操作

1. 选择河湾、林间台地或石岭候选，选择实际出现的 Origin。
2. 开局 18 位真实居民住在容量 24 的河谷合院里。看就业缺口和食物流量，再决定扩建什么。
3. 按 `2` 或点「圈地招标」，拖选或点选 1–7 个连通陆地格。**不再先涂区。**
4. 选 1–2 个发展 Tag，点「向社会发起招标」。农业方向的核心候选来自谷物农场、果园、牧场、菜圃，不再从整个生产大池中任意发牌。
5. 接受方案支付通货，材料随施工取用。点底部 DT 按钮推进整个 Block；遇到施工机会会提前停止，只扣已推进的 DT。
6. 点击住宅看实际住户、健康/幸福目标、服务比例及污染来源；点击公园/诊所/商业看实际服务了哪些住宅。图上绿色为服务、橙色为噪音/污染，金色仍为原 B 的成熟协作关系。

快捷键：`1` 观察、`2` 圈地（`3` 兼容圈地）、`Esc` 关面板、空格推进 1h。滚轮缩放，中键拖动地图。`F8` 为实验台；使用调试补给会标记存档，不能算正常游玩。

### 三个阶段

- **生存聚落**：只有食物、材料、能源和居民的住房/就业问题。没有可用制成品库存或制造业。
- **安居社区**：实际人口达到 22 且基础供给稳定 0.5 本地小时，开放商业、医疗、休闲和教育。新增生活需求在 3 本地小时内逐渐生效，解决方案先开放。
- **分工城镇**：人口达到 30、平均教育 25、供给稳定 1h 后，由你在「人口与阶段」主动确认。此时才启用低级制成品；商业逐渐需要它，基础制造业出现。

可以暂停迁入，也可以不升级阶段，继续经营原有社区。不靠任务奖励也能推进这一流程。中级/高级制成品不在本次切片里，**托卡马克之冠仍是整个 City 的结局**。

### 人口与需求

人口不再是住宅容量的别名。住户需要吃饭、就业、消费与公共服务；健康/教育/幸福分别影响劳动效率、技术岗位适配与迁入。商业只有实际顾客才产生商业税收，空住房不产生人口税。公园有维护成本，诊所有有限服务能力；放得太远不提供覆盖。

教育是住户技能，知识是教学/研究产出的可花费点数，两者不是同一钱包。界面「人口与阶段 → 查看知识与研究」解释它们的连接。

### 开发与验证

使用 Godot **4.7.2 Standard** 导入本目录 `project.godot`。运行游戏进入相同 B 主场景。主要实现仍在 `core/` 和 `ui/`，新增 `core/population.gd`，内容与平衡在 `content/`。

```sh
# 先设置 GODOT 为 Godot 可执行文件；Mac 常见为 /Applications/Godot.app/Contents/MacOS/Godot
"$GODOT" --headless --path . -- --test
"$GODOT" --headless --path . -- --playthrough
"$GODOT" --path . -- --ui-smoke
# 有相同版本官方导出模板的编辑器可直接导出：
"$GODOT" --headless --path . --export-release macOS build/MET_B_0.1.1_Population_macOS.zip
```

`MET_EVIDENCE_DIR` 可指定可写证据目录。此次运行日志在 `evidence/`；旧 B 日志在 `evidence_B_original/`，旧规格与说明在 `docs/archive/`。**本次数字只能引用当前 `docs/TEST_REPORT.md`。** 构建方式和局限详见 `docs/PROVENANCE.md`。
