# MET · 河谷初章

**EXP-003 / First Block MVP · 0.1.0**

这是一份可以继续开发的 Godot 项目，以及同源的 macOS 候选试玩包。不是 HTML 包装，也不是旧 P0 的玩法复刻。依据项目控制文件第16章 MVP-01～28 实现，从选址、起源、招投标、施工、资源与 DT，一直运行到升级、关系协作、治理危机、首块完成和无限建设。

**状态：程序规则与 Linux Godot 图形测试已执行；macOS 实机启动、Gatekeeper、Retina、触控板、原生文件选择器和性能尚未验收。数值可玩通不等于已经证明好玩。**

## 试玩

解压 macOS ZIP，把 `MET First Block.app` 放到本地目录后打开。包内带引擎，不需要安装 Godot、Python、模型或账号。Apple Silicon 需要 macOS 13.0+；Intel 需要 macOS 11.0+。推荐 1440×900，最小窗口 1180×740。中文使用系统字体，不分发字体文件。

本包无 Apple Developer ID / 公证。仅遇“开发者无法验证 / Apple 无法检查”且确认来源时，按 Apple 的单应用授权路径：先尝试打开，再到 **系统设置 → 隐私与安全 → 仍要打开**。不需要关闭系统级安全保护。若提示“已损坏”、恶意软件或实际崩溃，不要把它当作正常提示强行绕过，请保留报错。

官方说明：`https://support.apple.com/102445`。

## 第一轮操作

1. 选择一个 Block，再从锁定的两个 Origin 中选择起点。三块地图只开发选中的那一块。
2. 按 **2** 或点“涂用途”，拖涂定居 / 生产 / 流通 / 公共。按 **3** 切换“圈场地”，点选1～7个相邻、同用途、未占用的陆地格。
3. 选择1～2个政策偏好，再点“向社会发起招标”。三个候选不是精准查询；先读机制、实际输入和建设代价，再决定。
4. 中标立即付通货，材料与制成品按实际施工逐步取用。下方 **DT推进** 会推进整个 Block，遇施工提议提前停下，只扣已经走过的时间。
5. 按 **1** 查看项目的输入、输出、使用率、瓶颈、里程碑与邻接关系。仓库里“有材料”不等于“有兼容材料”。
6. 相邻且兼容的项目共同运行后，出现关系协作机会。关系不是两栋楼合成一栋；需要通货与少量制成品，可以暂时搁置。
7. 完成右侧五项清单获得奖状，仍可继续建设。治理失败是另一出口，失败地图保留为只读。

**快捷键**：1观察 / 2涂区 / 3圈地 / 空格注入1本地小时 / Esc回地图 / F8实验台。滚轮缩放，中键拖地图；“归位”可重置视角。

正常在线时间是1:1。不是让你盯着等：开局有DT，委托可以补给；离线城市不模拟，现实每小时积累0.5DT，最多72。外部已承诺委托的现实截止仍继续；首版窗口24～48小时，拒绝不算失信。弹出决策面板时本地时间暂停，Global仍按现实推进。

第一次尽量不使用F8补给。需要排查时可以使用，存档会标为实验，不冒充正常平衡。

## 存档与反馈

“存档 / 设置”里可以导出城市备份、恢复备份、导出实测报告、打开存档目录。报告包括种子、完整状态和最近事件，不会自动上传。请把它和问题截图一起保留。

独立 `user://` 目录名：`MET-First-Block-EXP003`。默认主文件 `first_block_v1.json`，最近备份 `.bak`。Mac通常在 `~/Library/Application Support/MET-First-Block-EXP003/`，以游戏里“打开存档目录”为准。不读取 P0、Flutter、ST 或其他私人文件。

重要操作即时保存，正常运行每5秒保存。已有手牌、RNG、重招成本都保存在同一快照中。校验用于损坏检测，不承诺单机绝对防作弊；换新局前请导出你珍惜的城市。

- `docs/BALANCE_AND_LIMITATIONS.md`：临时参数、真实未实现/未验证项；
- `docs/TEST_REPORT.md`：本次实际执行证据；
- `docs/SOURCE_SPEC.md`：本次实施依据第16章快照；
