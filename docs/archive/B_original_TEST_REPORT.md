## 已覆盖的关键规则

同seed同行为复现；载入后手牌/下一次付费重招一致；关面板与换场地不能免费洗牌；共享物资不重复结算；输入Tag不兼容不能产出；零能源停止耗能设施；升级真实施工、完成后才改变接口；旧库存不被升级追溯改写；关系需成熟、协作不重复领奖；DT Pulse与正常模拟共用路径；离线只加DT不补城市产出；时间回拨/上限保护；承诺逾期只处理一次；危机可修复/失败；完成奖状不锁图也不重复赠奖；实际磁盘主备份读写和损坏恢复。

## 尚未验收

1. macOS真正启动、Gatekeeper、Apple `codesign --verify` / `spctl`、公证：未测试。本包仅ad-hoc，未公证。
2. Apple Silicon/Intel的实际渲染、Retina字号、鼠标/触控板、native FileDialog、睡眠唤醒、帧率/功耗：未测试。
3. Godot编辑器源码导入及正规模板重新导出：提供工程与预设，但当前环境没有编辑器，未宣称执行。
4. 人工平衡、Draw Desire、空间规划欲望、关系养成、无限模式留存：全部待你实测。
5. 多日存档、跨版本迁移、大规模城市：首版没有完成这些验收。

## 测试方法可复现性

原始JSON与运行日志在`evidence/`；测试源码在`tests/`。模板构建/自验脚本在`tools/`。Linux图形运行使用Xvfb+GL Compatibility，程序化绘图与本机SystemFont，不带字体。

部分批量工具等待曾超时，但测试进程输出、JSON以及截图均实际落盘，已检查最终报告65/65、27/27与无脚本错误；不能据此推导Mac启动性能。

## 给真人试玩的一条要求

先按正常资源玩；感觉卡或烦时，先导出实测报告再开F8对照。报告的debug_used会标记调试介入，方便分清“规则问题”和“数值问题”。不要替原型硬找理由，尤其留意资源究竟有没有地方花、下一次升级有没有值得期待的机制。
