# B 0.1.1 人口迭代变更

## 来源与边界

在 B 0.1.0-exp003 上原位修改，不采用 C。第一 Block 的实验迭代，不宣布 B/C 总体胜负。没有修改远端 GitHub；源码包中保留原 B 哈希、基线提交与文本补丁。

## 本轮已实现

- **人口**：18 位实际住户、独立住房容量；空房没有居民税。拆住宅会先产生待安置人口，不会把住户直接删除。
- **工作**：全 Block 自动就业，劳动人口比例 65%；缺人降低运行效率。新住房不会立即凭空填满，迁入受到岗位、食物、健康、幸福、空位限制，可主动暂停。
- **生活**：健康、教育、幸福按住宅保存；医疗、休闲、消费、教育服务有半径和有限容量。重复服务不重复计算人口。
- **空间**：工业和部分商业的噪音/污染真实作用到附近住宅，点选显示影响连线和来源。公园、诊所、市场、学校的实际覆盖可以查看。
- **经济**：食物和材料是库存，能源为供需能力。资源接口标签停止匹配，不再区分重型/轻型/高级接口。建筑/地形/政策 Tag 继续存在。
- **阶段**：初期制造业和制成品不可用。人口推动安居阶段；人口与教育满足条件后，手动进入城镇阶段，才出现低级制成品及相关需求。中高级后置。
- **招投标**：删除涂区前置；1–7 Hex 场地+1–2 Tag 直接招标。先解释发展意图/项目家族，再在家族中随机加权，保留少量相关惊喜。
- **农业内容**：谷物农场、果园、牧场、菜圃分别提供平地产能、长成后收益、省劳力但有环境代价、高产但吃劳力/能源等选择，不仅更换名字。
- **商业**：前期本地农产品交换满足消费并产生税收；城镇期逐步引入低级制成品投入。真实顾客而非理论服务容量决定商业收入。
- **教育与知识**：教学改善住户技能；技术岗位看教育适配。有效教学产生知识用于研究，不把人口教育值直接当研究库存。
- **HP**：居民支持逐渐靠近真实生活幸福；严重短缺、低幸福或赤字持续一段时间后才侵蚀政治背书。原 B 的危机、承诺、升级、Fusion、DT、存档与结算保留。
- **升级**：增加省工、清洁生产、复合公共服务等用途；清洁生产只向有排放项目出现。早期升级/Fusion 不要求未开放的制成品。
- **界面**：基础供给/制造体系/居民三个主信息入口，制造体系晚显露；居民与阶段面板、住户信息和空间因果说明。

## 未实现或刻意保留

不模拟个体寻路、家庭年龄、阶层、通勤交通、动态物价和完整商业市场。就业是全区匹配，服务是局部覆盖。地图和基础美术保持 B 的形态，不宣称已经完成正式城建美术。

生产设施仍代表项目，不必手建仓库、下水、道路。一个场地暂容纳一个主体机械项目。主建筑依旧最多两次里程碑升级；协作独立在关系上，不吞掉原建筑。

正式多阶段 District/City、跨 Block、自治外交、Life、高级工业和托卡马克之冠均不扩进本版。资源 Tag 语法部分字段保留作存档/内容兼容，但不影响供给交易。

## 为什么不兼容旧存档

旧存档没有每栋住宅的真实居民、健康、教育和幸福历史；将容量直接灌成人口会改变税收、需求、劳力与阶段，且无法可靠恢复玩家城市的历史。因此新版使用独立 schema 2 目录，旧城市完整保留，不做伪迁移。
