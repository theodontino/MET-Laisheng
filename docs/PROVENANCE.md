# 0.3.2 来源与打包边界

源于用户对话挂载的0.3.1 Cardcraft源码与Mac包，在同一Godot工程修改。未取用不明工程、未发布GitHub。地图素材沿用0.3.0/0.3.1参数化素材；没有假装新增图像生成资产。

当前环境是Linux x86_64；Godot4.7.2原生运行时来自既有匹配引擎附件。Mac模板仅复用0.3.1的相同双架构引擎，旧游戏PCK完全替换为0.3.2。package_macos.py写入新Info.plist、资源封印与ad-hoc代码摘要，verify检查资源和代码页。这不是Apple签名/公证，不表示Mac启动通过。

对应独立Mac PCK与Linux嵌入PCK除嵌入基址标记外字节相同。报告会记录最终SHA。源代码包括打包脚本和全部当前测试；正式后续构建优先使用官方Godot编辑器与匹配导出模板。应用及源码均未包含字体文件。
