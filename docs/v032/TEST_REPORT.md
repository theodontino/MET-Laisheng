## 真正检查的用户动作

物资四按钮逐个点击，打开相应来源/去向和地图层；预算点击进入账本，推进后查看真实曲线；人口点击进入住房就业联合图，继续打开需求覆盖；DT详情与暂停切换，暂停后推进不可用、恢复后按原价真实花DT；政策全屏背景拖动到下面类别，选择生产税、确认只扣16通货且不改变RNG；任务确认前不改变状态，确认放弃后持久化、从可接页重新接取、打开历史；最后仍通过原生卡片选择农场、招标、支付施工和右上推进完成真实建设。此鼠标路径没有debug补给或直接调用经济API代替点击。

旧城保留测试使用0.3.1包中原来的实际路线存档，不冒充用户自己刚玩的存档；对照建筑、人群、报价、随机状态、库存预算DT、槽位和来源关系。展示截图部分直接载入这份有来源的城市，属于自动化界面证据，不宣称真人主观体验。

## 数据可信度

- 空历史不造旧曲线；一次实际周期一条历史，经营net×span＋一次性收支可还原钱包变化。
- 迁入事件不会被误记为包含全部经营收益的一笔迁入收入；批次迁入增长率明确为最近周期折算。
- 读取资源/人口/财政页和政策预测不改世界、RNG、钱包与历史。
- 暂停不积攒城市remainder；恢复不追算暂停期间时间；信息页暂停和手动暂停独立。
- 放弃任务停止该项奖励；重接合法、完成不重复领奖；已完成旧章不伪造刚刚完成日期。
- 人群加权包括待安置组；医疗教育独立；物资满足比例不伪装成实际服务人数。
- 720周期历史边界、嵌套坏档拒绝、保存还原后继续运行确定性均已检查。
- 开局粮食任务显示待首次实际结算，不用默认food=1绘制满进度。

## 途中失败与修复

1. 首轮检查中的旧档fixture未放入当前证据目录，补入源包真实fixture后重跑；没有拿缺fixture结果当通过。
2. 人口新开局页面展示下一周期预测，测试最初把它硬比较当前18人，修正为同一预测snapshot的实际人数；并非靠修改生产/出生值迎合测试。
3. 小屏时间区、物资区曾覆盖右侧详情/投标，改为使用剩余地图区域。低高度大字号的返回/详情符号出现空白或裁切，换用真实SVG图标。
4. 实际ScreenTouch测试发现政策页滑动未生效；修正ScrollContainer的触摸路由与滑动取消点击，然后重跑原生触摸按钮、拖动与无支付副作用检查。
5. 真实鼠标脚本首次查找`Advance0.5`，但Godot节点名为`Advance0_5`；修正只读几何定位，首次失败保留在diagnostics/physical-first，最终完整路径64项通过。
6. 两个中途快速退出探针偶见ObjectDB退出告警；最终完整UI/触摸/鼠标运行未出现该告警或脚本错误。软件图形驱动不支持切换VSync的警告仍存在，未据此声称任何Mac/移动端帧率。

## 布局与限制

当前原生窗口检查覆盖1440×900、1024×640、844×390、640×320与100%/125%/150%文字设置（不同检查覆盖组合见各JSON）。紧凑界面详情需要滚动；确认/返回/暂停有可用入口，并未声称所有信息在320高同时出现。政策各类别是在同一滚动页面，不是必须同一屏同时看清。

历史页面列最近60条，存档保留720周期和各300条事件；更早数据会滚动淘汰。旧版没有记录的历史确实不可回填。任务范围是已有四项社区成果与三个候选章节方向，不是完整随机任务/奖励许可/跨Block遗产系统。
