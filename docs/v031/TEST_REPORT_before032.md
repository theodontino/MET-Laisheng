## 实际检查了哪些用户动作

真实鼠标从开局选起源开始，打开生产工具、选择完整名称的农场卡、选地、打开三份投标、免费返回换地且候选/RNG不变、付款施工、使用DT推进；随后打开固定方案页签，真实滚动到空槽，点击征集，进入原生卡片投标，返回，再切明细和概况。

此路径无调试补给。`ui031.gd` 中为展示工业已装卡创建的局部fixture明确用了测试构造，**不把那张工业截图当自然经营成果**。住宅概况和图鉴截图来自正常新城，仍属于自动化UI流程，不是真人主观体验。

## 这次发现并修过什么

- 初次接入后，卡片作用尺度徽记因自动换行被挤成竖字，改为独立不换行徽记。
- 同时检查出展示配置叫allowed_hosts、实际内容叫hosts的字段差异，修正绑定并为全部40卡增加实时作用尺度核对。
- 大字号低高度的返回、详情按钮原来会只剩一个字；改用可解释图标和固定采用按钮，共同成本仍完整显示。
- 真实鼠标脚本初次把滚动区外的空槽中心当作可点击点，导致一次失败。修复的是测试只读几何输出与滚动脚本；最终实际滚动、打开空槽、征集和返回全部完成。初次失败日志保留在diagnostics中，不冒充通过。
- 最初继承回归脚本仍校验030版本号且缺少旧档fixture，已更新期望并补入真实fixture；最终162项重跑成功。
- 停产/零产出的生产建筑仍显示对应产出行，不因为本周期0产量而藏掉功能。

## UI与数据边界

卡片颜色是主题，三类槽类型由轮廓和明确标签表达；本轮不新增稀有度、资源、领域权限或套装。卡片点击不执行经济；费用与资格仍由既有内核在确认时校验。图鉴不附加虚构Provider/价格；真实投标或实例中才展示来源/合同。

窗口检查覆盖1440×900、1024×640/768、844×390、640×320，以及125/150%字号。小屏正文需要滚动，确认和返回固定；没有声称所有内容在320高同时可见。新界面不会每Tick重建相同结构的数值控件；卡结构或页签真正变化时才重建并保留滚动。
