# MET 0.3.1 · 城市构筑

版本：`0.3.1-cardcraft.1`。在现有 0.3.0 城市与远景上接入 UI 分层与原生方案卡，不是 HTML 排版稿，也不是另一款原型。

## 打开与接回旧城

解压 `MET_0.3.1_Cardcraft_macOS.zip`，打开 **MET Cardcraft.app**。本包包含匹配的 Apple Silicon / Intel 双架构 Godot 4.7.2 运行时，不需要安装 Python、模型或单独的 Godot。

**Mac 真机启动尚未验收；没有 Developer ID 签名或公证。** 本轮完成 Linux 同版本原生 Godot 运行检查，以及 Mac 二进制、资源和 ad-hoc 代码页摘要离线检查。它们不等于 Apple codesign / Gatekeeper 验证。系统拦截时保留原始提示，不要关闭全局安全保护或 SIP。

新版存档目录：`MET-RiverValley-031/river_valley_v4.json`，显示设置 `display031.json`。仍然使用 schema4。首次启动优先查找 0.3.0 的 `MET-RiverValley-030/river_valley_v4.json`；没有时再查找 0.2.1。可以选择导入或从菜单导入原有备份。

导入复制并校验旧城市，不修改原文件。人口、建筑、库存、预算、DT、报价、槽形、已装方案、原提供方与当前合同均保留；不重抽、不追发成果奖励。需要回退时打开旧版本与它自己的旧存档，不用旧程序反向覆盖新档。

## 这次可以直接看到的变化

### 建筑详情是三段固定框架

上方建筑名字、用途、运营者与数据时态固定；中间是「概况 / 方案 / 明细」；只有正文滚动，底部主要操作固定。

- **概况**先看居住人数、实际产出或服务，接着是运行状态、资源投入与维护，再看槽架。
- 健康、幸福、教育各有独立状态块。正常投入齐备显示正常，不再作为红色告警。
- 建筑没有岗位时隐藏“到岗0/0”与供人控制；真实新增岗位后才出现。
- 楼体和住户电力汇总到一行，但明细保留两者来源；建筑维护与住户维护分别列出。
- 同一周期的输入、实际产出、可入库/弃置、用工服务关系、场来源和完整修正链仍可查。
- 暂停是可逆管理操作；拆除在独立危险区二次确认。

### 槽位是容器，方案是卡片

「方案」页按建筑的真实槽形显示凹面插口：生产方形、物流六边形、运营圆形；真实 Flex 才显示双缺口。重复运营槽、弹性槽和来源依赖仍然存在，不增加新专业槽。

空位是虚线、加号和征集按钮；已装方案是带主题图、色带和名字的小卡。点开后看完整效果、替换、卸下、重签。点击只浏览或比较，明确确认才执行。

行业主题色不是槽类型、稀有度或强弱：工业黄、商业蓝、公共服务紫、居住绿、农业橄榄绿、设施青、通用灰。研究型医院可以是紫色生产卡，电商仓储店可以是蓝色物流卡。

自营数量来自当前合同和真实有效槽；仍然只是原有满配 +3% 小奖励。原提供方不会因为重签而丢失。依赖子槽没有卸空时不能悄悄删父方案。

### 40张卡使用同一组件

图鉴、投标工作台、已装槽位与方案详情共享卡片组件。图鉴可以按名字/ID搜索、按领域筛选。主题图复用原有建筑素材并配合程序纹样，不是40张新AI插画。

展示词条与当前 Rule 列表核对。价格由真实报价读取，不从排版样例拿固定价格。高级回收的一次污染投入共同产出材料和制成品，不画成两次重复扣料；粗野制造明确是制成品产出翻倍。

### 建设栏与资源身份

建筑卡的图片、完整名称和价格分开排版。窄屏少列并滚动，不再只剩“基础”“90通”。原来的居住/生产/商业/公共四组入口保留。

预算、DT、住房分组显示；资源有稳定图标、中文名与色彩，不改变资源分类或计量。地图图层、只读预测、DT和目标沿用0.3.0。

## 操作

点建筑 → 概况 / 方案 / 明细。点击空槽征集，点击已有小卡查看及管理。投标保持地图可见；返回免费且报价不刷新；比较时本地时间暂停。取消、关闭详情不会买卡。

手机式紧凑布局保留点选与确认；不要求拖卡或鼠标悬停。字号可设100/125/150%，正文可滚动，关键确认和返回仍固定。低高度大字号使用返回/详情图标与完整采用按钮，不把价格藏掉。

本包不是 iOS/Android 安装包。触摸布局和原生事件检查不等于手机真机验证。

## 没改什么

14个 `core/*.gd` 模块与0.3.0逐字节一致；核心内容 JSON 仅版本号不同。十类建筑、40个Bonus、8运营商、12政策、所有经济参数、城市目标、原料分配和DT语义保留。不加垃圾链、稀有度、额外槽型或新运营商。

本次不重新生成世界美术；继续用0.3.0素材。UI不烘焙成图片，文本、数字、按钮与卡片是原生控件；运行时不联网生成素材。没有分发字体文件，使用平台可用系统字体，实际Mac字体呈现仍需真机查看。

## 开发与复现

用匹配的 Godot 4.7.2 Standard 打开 `project.godot`；正常环境建议安装对应官方导出模板，使用 `export_presets.cfg` 的 macOS 导出项。

```sh
export MET_EVIDENCE_DIR="$PWD/evidence031"
"$GODOT" --headless --path . -- --test
"$GODOT" --headless --path . -- --test031-viewmodels
"$GODOT" --headless --path . -- --test030
"$GODOT" --headless --path . -- --playthrough
"$GODOT" --path . -- --ui031
"$GODOT" --path . -- --ui031-regression
"$GODOT" --headless --path . --export-release macOS build/MET_0.3.1_Cardcraft_macOS.zip
```

`--test030` 与部分继承的路线文件名包含030，因为沿用原回归脚本；只有当前 `evidence031/` 内重新产生的结果是这版证据。更早 evidence020/021/030 只是历史，不混算。

源码包含 B_030_to_031.patch、三份依据规格、显示JSON、原生组件、检查脚本与结果。没有同步到GitHub。
