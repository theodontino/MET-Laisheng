- 当前提交是一次性导入，不把历史文档里“未上GitHub”当成现在状态。

## 5. 必须覆盖的自动验收场景

### 时间与历法

T01：129600地球秒=1来生日；1555200秒=1月；18662400秒=1年，24来生时=36地球小时。

T02：×1活跃在线60秒，本地/外部均60秒、DT不变；暂停和离线相同时长均不推进两种模拟时钟。

T03：推进档真实60秒，本地1来生月，按额外时间扣DT；外部只推进60秒。

T04：拆成60个1秒/10个6秒或整段推进，同事件顺序下状态和账本在明确误差范围内一致。低速微小economic_delta不被舍入吞掉。

T05：剩0.01DT，按剩额反推可用本地时间，提交后精确0；不能实际多推进/多税收/多一批资源。

T06：年度、大周期、移民、施工竣工处均准确拆步；不一次跳过多个玩家决策点。

T07：离线90天，再开仅offline_recorded增加；生产、库存、钱、DT、人口、订单、周期、牌与随机流不变。多次打开只累计新离线段。

T08：系统时间回拨、后台挂起恢复、保存重载不补算/不恢复加速/不产生奖励。

T09：在同一最后时间片完成Commission且DT归零，获得建筑资格；归零之后才完成不追补。

### 外部贸易

M01：三个速度档下相同真实活跃时长，在相同输入/仓容/订单条件中，外部自然时间相同、基础贸易额上限相同；本地城市经历时间不同。

M02：多货运站/多订单共享额度，不按订单复制整份吞吐；缺钱、限价不满足、无库存/仓容时不成交。

M03：负买价/负卖价各自正确借贷记账，买卖差不倒挂；自然回归与实际成交压力分别产生。

M04：标准推进和燃烧档的港务任务无需真实在线等待数小时才能收到1单位货；若不达标调带单位的外贸参数，不暗改Local/External边界。

M05：自给城市外部比率很低不红警；真进口短缺必须能显示责任订单和库存风险。

### 奖励/Bonus

R01：同一帧年、人口、主题三个奖励生成三个稳定记录并按队列领取，不覆盖。

R02：同名Bonus可连续两次选，库存2；安装两次分别消耗1；卸下不返还，未装剩余Copy不丢。

R03：同宿主+30%三份合计+50%；×2三份合计×2.6667；不同宿主各自首份100%。正负代价按明确算法生效。

R04：纯布尔/结构重复不会产生1/3 true、隐藏额外槽或无穷Field；无新增效应不误扣。

R05：蓝图从0→1→2影响本Block已有/库存/未来Copy；等级不超过2，不扩大许可部署尺度，不跨局继承。

R06：0/1/2/3候选都可结算，重复已拥有不是非法；关页/读档不重抽。

R07：人口回落再达同阈值不重复；大量未安置移民不立刻刷稳定安居奖励。

R08：没有游戏内容偷偷向普通年度、旧城市目标或报价重抽返DT。

### 主题与归零

C01：未获重铸Token没有可执行常规换向；有Token但DT不足不扣Token；确认后Token/DT/未完进度原子变更。

C02：切回主题不重复领已完成里程碑；已入队奖励保留；交易/交付动态进度从切换点起算。

C03：DT归零未完成Commission，仅有命名；完成时才有主题建筑。重复打开/保存恢复不重发。

C04：Capstone无需剩余DT施工；满图不阻塞领奖；数值按单一Block来源一次生效。

C05：完成后的独立新局没有旧Copy、蓝图等级、Token、功能建筑或物资；旧局记录仍可查看。

### UI/性能

U01：正常、加速、施工、缺料、重复卡、升级、年+章重合、DT归零两个分支全部有原生运行截图。

U02：库存本地耐久与现实ETA换算正确；稳定净供给不显示虚假的耗尽倒计时。

U03：警报点击定位正确；全城同因故障合并；关闭泡泡不关闭硬警报。

U04：反馈/图层/预览/窗口缩放不改变玩法RNG和钱包；天气/水/零售价等未实现因果不被文案发明。

U05：大字号、低分辨率、返回、焦点和弹窗顺序可用，主操作无裁切。

P01：读取实际基准后测起点、成熟、满图；记录模拟CPU、UI刷新、峰值内存、帧时间，不把headless时长当GPU帧率。

P02：最高档加速不按倍率重绘UI；最大经济步长/资源边界仍精确。UI每帧与经济主循环分离，确保停止按钮持续响应。

P03：5年约720个“整日上限”不是实际调用次数保证。交易/施工/事件会产生子步，必须记录实测数量和耗时；不能为凑720隐藏必要结算。

## 6. 真实经营与体验验收

固定种子路线只证明可到达，不证明所有种子平衡。至少留以下对照轨迹：

- 自给型：不靠外部市场也能准备一轮加速；食品/电力可解释。
- 工业型：通过真实产出和交付完成主题，最后DT片段边界正确。
- 港务型：市场在高倍下仍可发挥作用，但库存和供给限制没有消失。
- 安居/农业/商业：各自不同投资重点，不通过同一套路一键过全部主题。
- 失败/改向：失去一次事件机会或使用稀有重铸，仍有可理解的后续，不凭空丢已得牌。

记录首个Bonus到达时间、每年收到牌数、停顿原因、DT花在哪里、主题完成时剩余DT、归零城市状态、贸易真实在线用时。75DT/五年/1~2小时整局都是待校准目标，不标“保证”。

真人观察重点：玩家是否为一次推进主动准备；是否能在地图读出瓶颈；奖励是否改变下一项投资；DT归零是否像一次建设完成而非单纯按钮坏了。
