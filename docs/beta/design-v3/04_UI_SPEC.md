# UI、图层与城市声音交付规格

## 1. 硬约束

城市是主画面；信息必须能扫；每个情境有一个视觉主动作；真实因果不因减字而被删除。历史资料记录过“隐藏关键数值只让玩家失去规划感”，因此详情必须可进入，不是全部藏掉。

L0–L3是注意力等级，不是必须点击四次的菜单层数。L3内部仍采用总览/管理/来源渐进展开，避免“总览又把所有历史表全倒出来”。

## 2. 四层内容

| 层 | 常态内容 | 触发与退出 |
|---|---|---|
| L0 仪表 | 名称/来生日期、DT、时间模式、通货、入住/容量；一个关键资源状态 | 常驻少量；正常时不显示全资源账本 |
| L1 态势 | 委任主题、关键下一条件、待领数、主要告警、小消息入口 | 异常消退后退出；相同告警合并 |
| L2 操作 | 点选建筑、升级预览、运营商投标、装卡、事件选择 | 只讲当前对象；返回保留地图与滚动 |
| L3 研究 | 财政、人口分配、贸易、政策、逐来源Rule、历史 | 玩家主动进入；首屏仍是主题总览 |

皮肤方向：殖民现场指挥终端，少量行政印记与勘探记录。不是中世纪羊皮纸、满屏赛博霓虹或现代OA表单。结构先行，复用当前建筑美术与领域识别。

## 3. 四个必交界面状态

### A. 常态经营

顶栏：Block名、来生日期、DT数与血条、×1/观察/推进/燃烧、通货、入住/容量。

右侧小卡：Commission主题、阶段、下一条最重要条件。无篇幅介绍主题目的。

地图只在异常处留必要标记。普通泡泡低频且短暂，消息不盖住当前选址。

主要入口沿用资源右下、时间右上、可折叠任务侧栏的已有方向；实机布局须统一，不机械保留造成遮挡的位置。

### B. 加速状态

显示实际档位、DT消耗、预计还能推进几年来生时间、按当前档位折算的现实剩余时间、下一年/大周期ETA、最重要资源缺口、一个“停止推进”主按钮。

库存耐久依据**净消耗**估算：`stock / max(0, consumption - expected_local_supply - expected_imports)`；非亏空显示“稳定/增加”，不是无穷多小数。进口限价不满足时不假装必有该笔供给。

同时标单位，例如“食物余量约2月 / 当前档约40秒”。这只是当前速率预测，非保本承诺。在旧回收/多配方城市里必须与真实模拟预览保持一致。

低外部比例但无进口需求不发红警。UI不再提供Reserve支援按钮、离线领奖按钮、免费Commission换向。

### C. 情境建筑

- 住宅：入住/容量、幸福/健康一组状态、首要需求瓶颈。
- 生产：输入→输出、运行率、关键投入余量。
- 服务：实际服务人数/容量、覆盖范围、可达但缺名额的区别。
- 物流：真实吞吐/额度、仓容、当前订单与限价状态。

等级最高时不突出无效“升级”。没有可调整生产配方的建筑，不编造“调整生产”按钮。主动作来自已有真实能力：升级、装配、查看供给、打开贸易。

Slot外框表达槽型；卡面/色条表达行业。重复Copy显示“首份/追加33%”，蓝图等级显示基础/I/II。给出安装前后总效果，不能只写含糊“1/3效果”。纯结构重复无增益时禁止误扣Copy并解释。

### D. 年度/大周期/尾声

一个时间点多种事件合并为同一结算容器，稳定次序处理待选奖励。年度与两年大周期重合不重复送普通卡，且不让多个弹窗互相抢焦点。

DT归零：先显示“高速发展预算已耗尽”，再显示名称输入和是否具备主题建筑资格。有资格才展示Capstone；没完成时诚实显示“本次未达成主题奖励条件”，不补隐藏惩罚。

保留“稍后命名”“继续常速经营”“结算记录并独立重开”。不能未经确认删除旧城、隐藏尚未领取的第5年奖励。

## 4. 颜色、形状、密度

领域色沿用：工业黄、商业蓝、公共紫、居住绿、基础设施青。状态色另外一层：警示图标/短色带，不把全卡染红而抹掉身份。槽型通过明确图标和外框识别；不单靠颜色。

同个事实只在必要层重复：HUD数字→详情解释可重复，标题+副标题+footer反复同义描述不允许。一级屏只给结论和下一入口；第二级管理页不放完整规则推导；来源明细再展开。

资源精确量仍可点开。正常不渲染所有库存、所有效率、所有账本为常驻数字。

## 5. 告警与城市声音

### 硬报警

从已提交状态生成，最多一个主瓶颈；严重时至多附一个次瓶颈。共因缺电不让50栋楼各弹长文，用局部图标和全城一条汇总。点击定位真实来源、打开对应图层/面板。

严重度阈值使用进入/退出滞后，避免闪烁；例如黄色进入<95%保持一段、恢复>98%后解除，红色由实际停工或生活严重短缺判断。具体时长用本地时间，UI去重/展示TTL用现实秒，二者不混。

### 市民泡泡

必须有地点和依据，点击跳到源住宅/人口。句子是体验表达，不伪造机制；单视口建议最多1–2条可见泡泡。可以关闭气氛泡泡而不关闭硬报警。

### 城市消息

反映较长趋势和事件，保留短历史；不承担唯一紧急通知。模板替换本地实现，不需要在线LLM。不加审批、瞒报、宗主国或政治合法性。

展示随机流与玩法流分离；隐藏反馈层、改分辨率、反复开消息页，不能改变下一张奖励和下一份投标。

## 6. 图形交付与无障碍

在真实Godot窗口交付常態、加速、四类建筑、重复装卡、蓝图升级、年度+主题双奖励、DT归零已完成/未完成两个分支的截图。截图注明夹具还是自然路线。

保留鼠标点选与触摸友好基础，但不宣称本Beta完成移动端发布。大字号、低分辨率、Esc逐级返回、地图不随侧栏缩放跳动、重要数字无裁切都是回归项。

不是要求每个动作只有一个按钮；是一个主动作，其余管理操作降为次级。拆除单独确认。
