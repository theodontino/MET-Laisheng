# Beta v3 单位与接入审计

基线：`3e7f00cb8aa0177df6f04e0ec490414bd8f019aa`，Godot `4.7.2.stable.official.ed1daf0bf`。开始时已有 README、AGENTS 和项目宪法的本地文档修改，原样保留并纳入本轮文档；未重置工作区。工作分支 `codex/met-beta-v3`。

设计来源为本目录 [design-v3](design-v3/00_READ_FIRST.md)，它取代先前离线储备可消费、唯一部署许可、目标完成即命名等设想。下面记录适配方式，不把参数初值等同于已验证平衡。

| 当前入口 | Beta 单位与消费者 | 适配原则 |
| --- | --- | --- |
| `beta_time.local_elapsed_seconds` | 地球等效秒；历法、DT、周期、主题时限 | 129600秒/日，12日/月，144日/年；只在显示层换算民用时。 |
| `beta_time.active_real_seconds` | 活跃在线秒；市场压力、外部吞吐 | 暂停/后台/离线均不推进。 |
| `offline_recorded_seconds` | 非负离线秒，只记录 | 不补算、不发奖励；UTC回拨取零，重复恢复不重复计。 |
| 兼容字段 `s.local_hours`、模拟参数 `h` | **来生经济月** | 字段保留以复用既有模拟器；所有新时间入口通过 Clock 换算，禁止解释为现实小时。 |
| `output.*` / `input.*` / 月账本 | 单位/月 | 库存不变，保持产消比例；所有资源必须由真实账本提交。 |
| `maintenance` / 人口维护 / 计税率 | 月度费用或实际税基系数 | 不把库存或税率再乘月秒数。 |
| CP / job.work | CP/月、剩余CP | 共享稳定队列，按实际工作扣材料，完工拆步。 |
| `housing` / `jobs` / `service.*` | 容量、名额 | 非时间率；不能逐月累加服务人数。 |
| `output.energy` / `energy_demand` | 供需能力 | 比例分配；储电与累计耗能才乘经济时间。 |
| 污染场 / 排放 / 回收 | 即时场强与月累计量分开 | 回收消耗真实来源配额；小时间步不被1e-6舍入吞掉。 |
| 健康 / 教育 / 幸福响应 | 按经济月的响应 | 保留目标值与响应方程；出生单独按3%年增长重新定义。 |
| 出生 / 移民 | 3%年率 / 每3来生月6人 | 本地时钟；原来有限四次到达改为明确周期到达。 |
| 需求宽限 / 小目标时限 | 来生月 | 沿用旧初值尺度而非现实小时；主题事件使用明确秒数边界。 |
| 外贸额度 | 标准货运站120单位/真实在线小时 | 保留来源能力修正、利用率、共享订单额度，不受加速倍率放大。 |
| 市场压力回归 | 900真实秒时间常数 | `exp(-external_seconds/tau)`；不是半衰期。 |
| Bonus数值 | 先蓝图等级，再同名同宿主重复强度 | `1+(n-1)/3`；结构/布尔/转换显式处理；不扩大许可尺度。 |
| 历史 / 周期 | 有界账本与年度摘要 | 不逐秒保存整城快照；城市收尾单独保存只读记录。 |

验收必须分别记录：数学换算、模拟夹具、真实玩家命令路线、原生窗口、人工体验。旧0.4测试的DT补充、唯一许可和旧目标命名断言属于被新规格替代的合同，不以删断言制造“旧套件全绿”。

平台范围：Linux原生窗口可在Xvfb+Mesa软件渲染中验证界面行为；其帧率不能代表桌面显卡。macOS/Windows硬件与人工试玩结果必须另记。pre-1.0不安排移动端专项开发与发布。
