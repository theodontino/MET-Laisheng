# MET 0.5.0-beta.1 验收记录

**功能验收通过；满图高速推进仍有性能限制。**

实施依据为用户提供的 [Beta v3 合同](design-v3/00_READ_FIRST.md)。继续原仓库的同一套模拟器，不另建演示游戏。起点提交为 `3e7f00cb8aa0177df6f04e0ec490414bd8f019aa`，工作分支为 `codex/met-beta-v3`；源码包内的 `SOURCE_MANIFEST.json` 记录最终源码提交与逐文件 SHA-256。

## 已实现的版本边界

- 正典来生日历、四个在线时间档、有限 DT、准确时间边界、Local Time 移民。暂停、后台、离线不结算城市；离线仅记录时长，无 Reserve 玩法。
- 按真实活跃时间推进的货运与市场，保留限价、库存、仓容、现金、共享吞吐、负价格和守恒。
- 年度与安居人口奖励队列、同名副本、同宿主递减叠加、12 张蓝图各两级研究。
- 五个委任主题、15 个阶段、15 个事件，稀有许可与 7.5 DT 改向。
- DT 首次实际归零的命名、完成资格定格、五种数值地标、满地图领奖、只读记录与独立重开。
- 地图常驻与四类建筑详情、原生奖励/研究/尾声界面、实际来源告警、泡泡和城市消息。

未改变五个主题的目标数值来让路线通过。旧版领域默认权重、旧 Slot 初始化和旧 Bonus Draft/奖励入口一并清理；移动端仍不属于 pre-1.0 实施或验收范围。

## 测试方法

使用官方校验过的 Godot 4.7.2 Standard Linux 可执行文件。必跑入口为 `bash tools/test_beta.sh`，细节见 [构建与验证](BUILD_AND_TEST.md)。数学/边界夹具、玩家命令经营路线、程序驱动原生界面、性能规模夹具分别保留证据。

时间分段测试明确区分浮点误差和免费推进。存档数值逐项比较允许绝对误差 `1e-12`（JSON 解析末位误差）；候选、来源 ID、队列与随机流按规范化值严格比较。不能用放宽容差掩盖多生产、重复奖励或丢失城市状态。

真实路线从正常开局出发，使用建设、升级、奖励选择、安装、交付、订单和时间 API。没有注入资源、人口、进度或 DT。测试提交的真实活跃秒数代表玩法时钟输入，不代表测试进程真的在线等待了这么久。

## 性能改动与口径

实测后删除了每 Tick 重复的规则编译、状态深拷贝和已收敛的重复资源分配；缓存纯六边格数学和按全部来源条件失效的空间投影。缓存位于存档之外，冷暖缓存、失效和回滚均有回归检查。普通 HUD 使用已结算快照，命令改变条件时才重新预测，避免每次刷新额外运行模拟。在线输入每 0.5 真实秒批量提交，内部日界/事件/预算边界仍准确拆分，暂停前补交剩余真实时间。

低帧率暴露了引擎帧 `delta` 截短的问题：在线时间现由单调时钟计量，暂停/后台/弹窗处明确清空或结算对应区间，不靠系统 UTC 补算。

原生性能使用 Linux Xvfb / Mesa llvmpipe 软件渲染、1440×900 窗口。记录 2／12／53 建筑的静止、平移、缩放和实际 App 高速推进，包含帧时间、模拟 CPU、界面刷新、内存和停止加速回调。自动保存关闭，另测序列化成本；报告不包含磁盘写入延迟。Headless 时间不能换算为 GPU FPS，旧 M5 Max 数据也不能与这台云主机直接比较。

## 交付与未验证事项

源码 ZIP 包含真实 `project.godot`、入口、GDScript、资源、内容参数、测试和文档，附成员 SHA-256 与 ZIP 校验；独立解包启动的结果单独写入交付证据。样例存档来自明确标注的自动经营路线，不收集用户存档。

本次验证不等于所有种子已经平衡，也不等于真人完成了 1～2 小时体验。主题达成后仍可能因新增人口、库存或供电变化再次出现瓶颈；已完成主题保持达成状态，这是里程碑语义。后续优先进行真人节奏与可读性试验，以及满图性能测量。

macOS / Windows 原生硬件和打包运行未验证。桌面导出配置已补齐 Beta JSON 与版本信息，不能因此宣称安装包或平台验收通过。没有自动推送或发布 GitHub。

云环境当前实例的引擎、导入和运行入口已验证，复用启动说明已保存。新任务对仅存在本地的 Beta 提交或快照的恢复尚未验证；保留源码交付包，不把远端 `main` 当成已经发布的 Beta。

### 原生界面与性能

18 张原生帧缓冲截图覆盖常速、燃烧、四类建筑、升级/施工、重复副本、蓝图研究、年度与大周期、两种归零结果、地标、只读记录及 900×620 / 150% 字号。除截图保存外，还验证了 Esc 返回与焦点、实际指针点击物流入口、主操作无遮挡、告警定位、常速停止不强制预演和剩余 0.37 秒完整补交。主代理复查了预算常显、物流主按钮与大字号小窗口截图。

性能结果见[同场景修复前后报告](PERFORMANCE.md)。53 建筑燃烧帧 p95 从 495.2 ms 降到 183.3 ms，停止回调从 768.5 ms 降到 178.6 ms；真实时间补交误差最大 30 µs。**仍存在明显长帧，性能验收没有标为“所有场景稳定 30 FPS”。** 静态软件渲染也有波动，完整表格保留了变差的样本，不仅报告改善项。
