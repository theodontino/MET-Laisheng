# UI6 页面重制与交付记录

日期：2026-10-23。应用版本 `0.7.0-ui.6`。设计依据为本次用户批准的页面重制计划，以及随后明确的“左侧面板延伸、摘要侧栏 → 详细决策页”修正，见 [当前合同](CONTRACT.md)。

## 本轮行为

- 城市、经营、Bonus、任务、档案采用贴合左侧导航的摘要页；详细页从摘要按钮进入，按职责使用不同宽度与分栏，保留固定操作区。
- 一级页仅提供“收起侧栏”；详细页写出实际返回目标，例如“返回经营”，另有“关闭面板”。地图定位提供命名返回入口，返回后恢复选项、展开状态和滚动位置。成长路线并入任务。
- MET 标识打开系统设置。顶栏显示当前街区库存、数值变化，点击进入相应明细。右上显示 CP 使用／预留和电力占用／供给；完整来源可继续查看。
- 收支表展示真实周期的期初、收入、消费／施工、外运、委任交付、损耗和期末。经营月率、主动操作与真实在线交易分别说明。Bonus 库存、目标／槽位、同一步比较与安装操作分区；任务、奖励、市场、政策及城市管理保留各自职责。
- 主页面、分栏和地图来源滚动灵敏度为 48，说明浮层为 24。普通说明与地图悬停沿用两秒计时并显示细进度条。
- 主建筑入口落到环路最近线段，短支路收在门槛至环路之间；近水平门口增加短铺面，真实附楼连接保留。详见 [道路独立图证](UI6_ROAD_EVIDENCE.md)。

本次没有修改模拟核心。与本轮开始时的本地备份比较，`Assets/MetCore` 的 99 个文件内容保持一致。当前 checkout 原有的城市、地区、科研等未提交实现仍被保留，并作为这次实际构建的既有基础；不能把这些既有功能全部算成本轮新增。

## 真实输入

用户在最终界面构建中实际检查“经营 → 市场与订单”报价滚动、返回与点击，以及顶部材料两秒悬停和进度条，明确回复 **“都正常”**。见 [人工确认](evidence/ui6/manual-confirmation.json)。

CUA 键盘事件可进入 Player；鼠标工具曾报告 `noWindowsAvailable`，随后虽接受点击，Unity 读取的位置没有变化。因此没有把这些工具调用当作成功的鼠标验收，也没有使用其他系统输入方式绕过。真实输入结论来自上述用户检查，范围不扩张成每一个页面的真人全流程。

## 构建与发布边界

应用为 macOS Universal（arm64 + x86_64）包，使用项目既有 ad-hoc 签名流程。它不是 Developer ID 签名或 Apple 公证；实际运行平台证据为上述 Mac，未声称其他设备性能或移动端支持。

发布使用当前构建源码的独立 Git 快照和对应 prerelease；不改变现有开发分支 HEAD、真实暂存区或未提交工作。应用 ZIP 保留完整 `.app` bundle，旧发布及资产不覆盖。原生验收测试存档位于忽略的 `build/ui6-evidence`，不进入应用包或玩家日常保存目录。
