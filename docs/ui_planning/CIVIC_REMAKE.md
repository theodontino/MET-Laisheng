# Civic UI：概览、管理与对象检查

2026-10-29。适用当前 Unity checkout，沿用 2560×1440 全屏、独立界面大小与字号。此页记录当前实现与交互分工，实际检查结果另附；不代表真人试玩验收。

## 本轮纠正

旧的“详表”只把侧栏拉宽，内容与操作顺序基本相同。现在把两种界面拆成不同的阅读任务：

- **经营概览**依附地图，回答当前缺什么、哪里有问题、最常用操作是什么。使用容量条、少量重点数值和短名单。
- **全屏管理**回答多个对象有何差异、哪一项优先、来源如何核对。固定表头、可筛选排序的对象列表与所选项检查区联动，各区域独立滚动。
- **地块面板**固定属于地图左下角，展示当前地点，不能变成全局栏目的子页面。
- **操作窗口**负责新建、升级、奖励与需要确认的修改。保留独立草稿、限制和实际支付，不写入页面访问历史。

## 页面分工

| 工作区 | 地图侧栏 | 全屏管理 |
| --- | --- | --- |
| 居民与服务 | 住房、就业与服务容量；不足入口和常用生活措施 | 住宅、住户组、工作地、提供者四种清单；筛选、排序、同列比较；所选对象的就业去向与实际服务来源 |
| 资源与财政 | 库存与净月流、主要贡献条 | 按资源比较各建筑产出、投入、居民消费、施工领料与库存；通货归属与电力供需使用各自口径 |
| 市场 | 当前订单、简单下单、希望城贸易进度 | 报价、订单与实际成交分别列表；选择后在固定区域编辑或检查；费用与限制靠近下单按钮 |
| 政策 | 当前方案、候选与主要改变 | 同类候选横向清单；所选方案的同一步预测与实施代价 |
| 施工 | CP 使用、主要瓶颈、正在进行的工程 | 全工程进度、材料、等待原因、优先级对照；所选工程控制；临时施工队合同管理 |
| 任务与成长 | 当前目标、缺口、办理入口；短成长路线 | 目标/合同清单与办理区域；三阶段要求及奖励对照；已保存成果检索 |
| Bonus | 库存与常用目标操作 | 库存、目标与槽位、变化与确认三栏；不把未变指标挤进比较 |
| 档案 | 直接进入管理 | 分类/检索、时间顺序列表、所选记录正文与来源；完整记录就地展开 |

## 导航约定

1. 点击左侧栏目打开经营概览，恢复该栏目的访问状态。
2. “打开管理页”进入独立全屏阅读面。地图 HUD 收起；管理页顶部允许在同级栏目切换。
3. 选中列表行只改变检查对象，不能提交经营操作。
4. “地图定位”暂时收起管理页，显示“返回原列表”。返回保留栏目、筛选、所选项、逐层展开的来源记录和各自滚动位置。市政储备等公共来源没有地块，不提供虚假的定位按钮。
5. “经营概览”回到相应地图侧栏；关闭管理页回到地图。跨栏目不产生虚假的父子关系。
6. 输入框拥有键盘时，按键不传给地图。Esc 优先释放输入或关闭最上层；地图的 Shift 数值开关和 L/Shift+L 保留。

## 可读性与数据边界

- 正文保持自然行高，纵向容器不得通过收缩文字高度填满屏幕。容量条标题与条体独立占位；内容超出时滚动。
- 默认深色不透明阅读面；正文浅色，次要说明也必须清晰。悬停说明独立设置字体、前景色与背景色，不依赖父容器继承。来源的展开、悬停和焦点文字也使用明确的浅色样式，避免落回默认深色字。
- “待结算”、无记录、不适用和实际零分别表示。列表读真实快照，按钮复用既有命令。
- 资源保持原单位；就业人数、可用岗位与名义岗位分开；服务池容量不按成员建筑重复计数。
- 本轮不修改星图、科技、Bonus 或经济规则，不把新界面当成 G2 以后玩法已经实现。

## 工程结构

`CivicShell.uxml` 管结构，`CivicShell.uss` 管样式，`CivicToolkitView` 管显示比例、滚动与焦点。`CityCivicManagementOperating` 和 `CityCivicManagementDevelopment` 专门绘制全屏管理页，独立于概览渲染函数。原有升级/星图窗口继续接既有真实快照与模拟命令。
