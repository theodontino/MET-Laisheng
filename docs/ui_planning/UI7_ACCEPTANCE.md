# UI7 常用页与固定导航重组

日期：2026-10-24。应用版本 `0.7.0-ui.7`。范围以本轮批准计划及 [当前界面合同](CONTRACT.md) 为准。

## 已实现

- 左侧改为城市（暂未开放）、居民与服务、施工、财政、Bonus、任务、档案。取消城市状况中转页；常用页包含真实列表、缺口和操作。
- 详表具有固定栏目和父页；切换栏目保存选择及滚动位置，不产生跨栏目返回链。财政和任务的同级标签不增加返回层。局部建筑详情保留来源栏目，地图定位保留命名返回。
- 常用页只保留右上关闭；详表在标题区提供明确父页返回。保持左侧对齐、固定操作区和原有宽表比较。
- 顶栏两秒悬停按指标展示当前街区库存、服务、经营和容量信息；首次结算前显示待结算。说明支持移入继续阅读及关闭；悬停不打开管理页。
- Bonus 领取留在任务，使用已有副本从 Bonus 明确进入部署比较。任务常用页直接展示阶段条件和可交付合同；有口粮保留要求的合同扣除保留量后显示可交付数量。
- 永久城市管理、交班、回任、后续扩张、跨区物流、科研和城市工程入口封锁；已有数据、初次开局、本区政策、市场、奖励和街区结算保留。永久城市历史只读可达。

本轮与修改前备份比较，`Assets/MetCore` 的 99 个文件内容一致。原有未提交工作保留；已有城市系统并非本轮新增。

## 构建范围

使用 Unity 6000.6.5f1 构建 macOS Universal 应用。应用采用 ad-hoc 签名，不是 Developer ID 签名或 Apple 公证。验收使用隔离存档目录，不覆盖玩家日常存档。发布保留原开发分支、真实暂存区及未提交文件，通过独立源码快照记录实际构建。

## 悬停可读性修正

用户指出资源说明堆叠结算术语、不适合玩家阅读。顶栏说明改为库存、月变化、关键缺口和明确点击去向；删除周期小数、零值流水和在线贸易规则段落。月变化统一按最近结算折算并简短标注；首次结算前仍显示待结算。正文由 15 增至 18，并使用高对比正文色和不透明深色底，防止下层页面文字透出。逐笔凭据及完整来源保留在原详表。新增原生内容高度检查与粮食说明截图，验证常用顶栏说明在基准字号下不需要滚动。此项视觉检查与此前用户的真实输入确认分别记录。
