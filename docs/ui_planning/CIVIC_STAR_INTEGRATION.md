# Civic UI.2：本地 UI 与远端星图整合

2026-11-01。基于 Civic UI.1（已包含远端 Wild G1.1），保留当前本地星图配置、住房设计 II 与奖励改动。

修复普通城市未启用 Wild 时没有星图入口的问题：农居显示“启用建筑星图”，先展示确认说明，取消不启用；确认通过现有 CitySession.EnableWild 命令建立设计档案，随后打开真实星图。已启用的农居直接打开星图。

没有覆盖本地工作目录或操作实际玩家存档。启用会使用既有规则调整基础 CP 并发放一次开局补给；确认窗明确说明。历史街区仍不可编辑。

工程验证：星图核心241项、希望城贸易59项、本地新增科技与奖励177项；实际2560×1440 macOS Player 328项合成事件断言通过、16张截图，含普通城市启用入口、取消、确认、施工、升阶与撤销。该结果不是原生鼠标或真人试玩验收。测试只读写显式隔离目录。

应用为 Universal macOS、本地 ad-hoc 签名，未做 Apple 公证。GitHub发布用独立源码快照；当前分支、HEAD和用户暂存区保持原状。
