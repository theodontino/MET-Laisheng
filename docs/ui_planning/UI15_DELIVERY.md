## 修正范围

| 原盘查 | 本轮处理 |
|---|---|
| 1 首次结算口径 | 居民、服务、电力及建筑详情在没有实际结算时标明“待结算”；初始状态、库存和额定容量继续显示真实值。 |
| 2–3 对象检查与地图返回 | 建筑使用附属抽屉，主列表、选中对象、滚动和高级模式保留；详表定位后可继续选地块并返回，单独建筑抽屉回程不打开虚假工作区。 |
| 4–5 目标和通货落点 | 统一目标处理入口，带入医疗等服务筛选、粮食／制成品／电力等资源；保留“回到此目标”。顶栏通货明确选中财政来源。 |
| 6–8 建造决策与密度 | 候选横向选择，主要变化／投入约束双栏，真实成本集中呈现，固定取消与确认；同一步城市变化默认折叠。恢复表面色层级，容量与来源采用紧凑横排。 |
| 9 政策 | 收支／市场／政策均可在紧凑页切换；先显示变化指标，未变指标折叠；完整页保留全部资源投入与效果，固定实施费用和支付后余额。 |
| 10–11 居民和提供者 | 增加建筑住房容量视角、空住宅及排序；住户仍按真实群组处理，服务池容量／使用和来源可检查或定位。 |
| 12–14 财政与市场 | 接现有逐建筑财政来源，替代对应聚合解释而不重复累计；资源、电力和财政使用对齐来源表。订单增加状态筛选，成交历史可继续翻页。 |
| 15 施工 | 项目列出地块、等级／方向、运营者与身份；保留真实优先级、暂停、定位和临时队命令。 |
| 16 Bonus | 紧凑与完整页共享库存／已部署／目录筛选及搜索；没有副本可做只读比较，安装仍受真实副本与资格限制。 |
| 17 奖励 | 任务保留紧凑待领项，候选在独立窗口中选择；领取回执可留在任务或明确前往 Bonus。保持真实 FIFO 队列。 |
| 18 档案 | 搜索、分类、结果数及分页，旧记录可查；不补造历史。 |
| 19–21 地图与 HUD | 图例接真实颜色范围与单位，Shift 提示保留；紧凑工作区不独占地图快捷键，输入框优先处理 Esc；收起的下一步保留目标值，上限目标显示阈值。 |

## 明确保留的边界

- 2K（2560×1440）默认全屏，UI 80／100／120% 与独立字号。
- 地块依附地图，独立放左下；管理页、对象抽屉、操作窗口各自拥有关闭／返回语义。
- 真实结算、施工、市场、任务、升级专业化和临时施工队规则继续使用原命令；未改玩家存档和保存格式。
- 只读旧街区保持只读；永久城市管理不开放，不新增“回任”。
- 原盘查第 22 项开局流程未改：正式开局命令的执行时机与随机过程继续保留，未照搬演示的最终确认前草稿。
- 这是本轮实现和工程核对记录，不宣称已完成像素级一致或真人操作验收。

## 检查与证据

Unity 6000.6.5f1 实际导入与编译通过。新增定向检查通过 **47 次页面渲染、3,020 项断言**，生成 **15 张 2K 隔离 Editor uGUI 图像**。检查覆盖首次结算前口径、真实目标目的地、详表／建筑抽屉／地图回程、建造与升级九组 UI／字号组合、奖励独立窗口、文字真实字形与边界，以及浏览／取消不改变会话与 RNG。隔离检查没有建立玩家存储目录。

现有 V3 工作区回归在最终源码上通过 **185 次页面渲染、4,365 项断言**，覆盖 UI 80／100／120% 与字号 100／125／150%。

新增核心只读预览检查通过 **17 项**：无副本目录比较、真实同一步效果、替换资格、空库存保持、真实状态／已装来源／RNG 不变。依赖漏洞信息源网络不可达的 NU1900 提示不影响已缓存依赖编译；未改包版本。

实际查看本轮图像后修正了检查数量本身不能证明的问题：中文字库行高导致名称和费用整行被裁；候选状态标签挤占名称宽度；奖励规则值窄列换行重叠；Bonus 插图没有获得实际占位高度。对应工程检查增加了完整字形、首选高度和相邻区域边界约束。

这些是实际 uGUI 排版图像，黑色底图来自隔离场景，**不是运行中的 Player 城市截图**。用户负责视觉及实际鼠标键盘验收。已知 Unity Editor SearchDatabase 启动索引异常与游戏检查分开保留，未作为游戏错误或运行体验通过的证据。

结果及图像见 [UI15 工程证据](evidence/ui15/)；原始 Unity 日志保留在 `build/ui15-checks.log` 与 `build/ui15-v3-regression.log`。
