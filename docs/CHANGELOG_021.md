# 0.2.1 河谷新章：本次改了什么

在交付B0.2.0源码上继续改；保存原设计、内容和来源历史，不另造小原型。

## 玩家能直接遇到的变化

1. 研发清单改成「稳定生活 + 自选城市成果」。宜居、交付、旧区改善三种方向，要求和进度可点击查清。奖励来自一次性城市成果，不再靠反复盖楼凑数。
2. 默认画面以地图为主，最多两条城市消息；常驻侧栏取消。建筑、环境、政策、方案的细节按需打开。
3. 建筑选址和每份投标都能先看下一周期真实预测。免费返回/撤回/换地，原报价保留。初始造价不重复抄三份。
4. 40个方案都有简明中文要点，完整规则保留在详情。近邻收益、缺工缺电、回收没有污染可吃等情况可提前提示。
5. 账本将产、用、弃分开。普通产出、额外配方、住宅生产、污染回收、电力都进入统一来源明细。财政的税与维护也分来源。
6. 修复原料被无法运行的工厂白预约的问题；加入确定性有限回补。用电需求先受可运行上限约束，不能让没有人/料的工厂先虚占全部电力。
7. 新需求不再暗开。居民制成品消费要玩家公布计划，给2小时准备；服务需求有固定预告和渐入。迁入在显示的边界触发，不拖到9.1小时。
8. 开局不推进时间也能看供电与就业预测。刚完工的建筑不会用上一个施工周期的零产出冒充正式运营结果。
9. 普通健康/基础教育以100%人员效率为参照；食品、制造产能与需求一起调，地形更有基本意义。不全局削发电或加岗位制造饥荒。
10. 运营商给予不同初始槽形；同源满配仅3%效率。支持付费重签、空槽改型、换运营者，保留来源与槽位历史。
11. 河谷微缩风格重绘10类建筑，学校/诊所不同轮廓；施工、停工、投入不足、运行状态不同。关系线只在需要时出现。
12. 0.2.0旧城安全迁移到独立目录；原库存过量有过渡保留容量；连续微量溢出人口按同来源合并，不生成数百个无家可归碎片。损坏主档不会覆盖有效备份。

## 没有借机加入的东西

没有新引擎、独立HTML、跨区运输、垃圾/噪音新链、复杂企业财务、定时Bonus、升级树、完整District/City。原40个Bonus、8运营商、10建筑、12政策均保留。进一步扩展写在原计划中，没有伪装为已经完成。

## 刻意说明

只读预览是假定当前建筑已完工后的一个周期，不是长线最佳解；额定地形高亮不是综合推荐分。所有资金、成本和目标阈值都是这版的实际起始平衡，不宣称最终平衡。
