# 0.3.0 更新说明：城市与远景

以 B 0.2.1 原源码为唯一基线，保留原有玩法与经济。

## 本次已经进入游戏

1. 固定世界坐标与独立镜头：全图、社区两个归位目标；侧栏不再缩放地图。
2. 新二维建筑素材、连续河岸、地形植被、视觉道路、施工和运行状态；分析时背景降低饱和度。
3. 地图与状态标记分层绘制；普通图层不会每帧重新执行整套经济计算。
4. 医疗、教育、购物、休闲四种服务分别显示可达性、实际服务与容量缺口；不再跨种类取最高值。
5. 环境、热、就业、物资、电力与组织图层分别保留自己的量纲与来源。连接是实际分配关系，不是不存在的车流。
6. 非模态投标工作台：点击方案只预览，地图仍可操作，本地时间明确暂停；关闭和返回不洗报价。
7. 本次改变使用“无行动的下一周期”对比“方案完成的下一周期”，有逐地块服务、环境和运行差分。
8. 16条LRU预测缓存；候选按revision/tick校验；过期时先刷新再确认，不直接提交旧预测。
9. 城市问题入口提供检查现有设施、规划新设施、查看人口需求及政策等解法。
10. 手机横屏重排、ScreenTouch/ScreenDrag/双指缩放、125/150%文字、减少动态、图层锁定、恢复原图层。
11. 首次完工只提示“建成”；有实际后续运营记录后才提示实际贡献。不会提前庆祝还没有发生的收益。
12. 旧城和显示设置分离，0.2.1导入不改写旧文件。

## 不是本次完成的内容

没有移动端安装包和应用商店发布；没有真实Mac/手机启动、Retina、触控板、热稳定性认证；没有保证最终游戏性或最终美术质量。0.3.0是可玩的UX/美术更新候选，不是静态原型。

纯AI透明精灵量产没有按原设想落地：本轮图像工具返回整页概念图，因此最终资产由可复现的参数化插画脚本生成并入库。十类主体和复用配件已经可用，但后续仍可逐项替换为更精细的美术而不改变坐标、规则和图层。
