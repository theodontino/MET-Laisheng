# MET 0.3.0 · 城市与远景

版本：`0.3.0-cityview.1`。继续在 B 0.2.1 上实现，不是另一个引擎、HTML 原型或静态效果图。

## 打开

解压 Mac 包，打开 **MET City View.app**。包含 Apple Silicon / Intel 双架构 Godot 4.7.2 运行时；不需要安装 Python、GPT 或单独安装 Godot。

**Mac 尚未真机启动验证，也没有 Developer ID 签名或公证。** 这里完成的是 Linux 同版原生引擎运行与交互检查、Mac 包结构与代码页摘要检查。它们不等于 Apple codesign/spctl 或 Gatekeeper 验证。若系统拦截或提示损坏，请保留原始提示；不要关闭全局安全保护或 SIP。

## 接回旧城

首次启动会查找 0.2.1 的 `MET-B-Rivervalley-021/river_valley_v4.json` 并询问是否导入。菜单中也能手动导入备份。

新版使用独立的 **MET-RiverValley-030/river_valley_v4.json**，仍为 schema4；显示设置放独立 `display030.json`。不覆盖旧版。保留居民、库存、预算、DT、运营方、方案提供/签约方、已抽报价和原槽位。需要回退时直接打开原 0.2.1；不要用旧版反向覆盖正在使用的新档。

## 现在怎么操作

默认看城市。下方按居住、生产、商业、公共服务选择建筑。点位置只是规划，比较投标也不会落楼，只有明确的“采用并建设”才付款。桌面悬停只是快捷方式，不是必要步骤。

投标现在是地图上的工作台，不盖住整座城。比较期间本地时间暂停；可平移、缩放、换位置、切方案。返回保留原报价，重抽另行收费。方案槽的替换、地区和组织方案、政策也保留入口。

图层包括地形、医疗、教育、购物、休闲、环境、余热、建筑缺人、居民找工作、粮食、材料、制成品、电力、运营组织、本次改变。四种服务独立读取真实分配。实线是可达范围；住宅百分比是实际服务；斜纹是可达但容量不足。点建筑后可查来源。投标的虚线范围和增减数字是预测，不是已经发生的收益。

资源栏的库存是当前物资，产用弃按标明的最近实际周期或下一周期预测显示；展开账本能看完整来源。预测只比较同一基线下的两个下一周期，不保证长期效果。

鼠标滚轮缩放，左键拖动空地图或右/中键平移。两个镜头按钮分别回到社区、查看全区。打开侧栏不会改变格子的世界尺寸。Esc逐层返回；输入框中空格不推进时间。

触摸方式为点选、单指拖图、双指捏合、按钮确认。支持窄横屏重排，三份方案改为纵向摘要，详情切页。菜单中可设100/125/150%字号、提高对比、减少动态及紧凑布局。**原生触摸事件已在运行时注入检查，但没有 iOS/Android 真机验收，本包不是移动端安装包。**

## 没有改变的玩法

十类建筑、40个活跃Bonus、8家运营商、12项政策、城市成果、DT与既有经济参数保留；内容表除版本号外与0.2.1一致。没有借美术更新加入垃圾链、噪音新链、跨区物流、自由旋转三维、企业财务或新一轮升级树。

## 美术生产的实际情况

本版实际接入30项统一的二维地图素材：10主体、12装饰、8类可复用方案配件，另有32个SVG图标、8个组织徽记、6个轻量反馈音。它们是本轮编写的**可复现参数化插画/音效脚本**生成的，不是把生成的整页概念图铺成可点击底图。

这是与原方案的一项明确执行差异：图像生成工具本轮给出的是整页界面概念图，未作为合格透明精灵入库。最终用统一脚本完成可工作的素材集；未声称已经验证了纯图像生成工具的批量母版生产管线。所有新地图素材、原始脚本和来源记录随源码提供。运行时不调用图像模型，不联网生成美术；也不分发系统字体文件。
