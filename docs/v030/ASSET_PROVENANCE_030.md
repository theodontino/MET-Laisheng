# 0.3.0 新素材来源与再生成

所有新地图主体/装饰/模块由本轮编写的tools/make_art030.py生成：固定斜俯视投影、平面材质、深度缓冲、超采样、透明底。不是运行时三维模型，Godot只加载两张图集。它与原计划“用图像模型逐栋出图”不同，实际差异在计划落实表和更新说明中明示。

- 单栋主体512×512；装饰/配件256×256；图集两张2048×2048。
- 所有新图标、组织徽记及声音由tools/make_ui030.py生成。
- 高分辨率母图不进运行PCK。运行时不连接生成服务。
- art_catalog.json记录每项素材路径、alpha边界、地面锚点、atlas矩形与SHA256。
- 40份活跃Bonus均有视觉绑定；无新增模块的方案保留现有主体，通过状态、图层或身份呈现，不强行为每份卡画整栋楼。
- 不分发系统字体。中文使用平台SystemFont：Mac优先PingFang SC，其他平台使用系统可用CJK回退。
- 原Godot引擎MIT许可与原项目第三方声明保留。没有下载其他商业游戏素材。

再生成美术需要Python、Pillow和NumPy；这是开发工具依赖，不是玩家运行依赖。运行两个tools脚本后，在源码中重新打包。图集对齐与Alpha检查记录见evidence030/final/asset-audit.json。
