# MET 0.4.0 · 专业化与委托

继续 0.3.2 城市工作台与 B 系谱，在同一座可经营的河谷城市中加入建筑成长、委托许可、市场贸易。当前为 pre-alpha.3；运行引擎为 Godot 4.7.2 Standard。

本轮为 **来生殖民城市版**：固定视角的半写实微缩城市，从先遣模块、定居小镇发展为都市化街区。建筑、原生蕨类样植被、连续高程、地基与相邻附属建筑统一组合，镜头平移缩放复用缓存世界层。

macOS 包为 `build/MET_0.4.0_Laisheng_macOS.zip`，Windows 包为 `build/MET_0.4.0_Laisheng_Windows_x64.zip`。旧 `Visual` 包保留。Windows 解压完整目录后运行 EXE，并保留同名 PCK。

Android 测试包为 `build/MET_0.4.0_Laisheng_Android.apk`；iOS 提供未签名 Xcode 工程。构建、自动检查、桌面画面与移动端实机验收分别记录，见[本轮说明](docs/v040/LAISHENG_041.md)和[验收记录](docs/v040/LAISHENG_ACCEPTANCE_041.md)。[三阶段与同状态画面对照](docs/v040/LAISHENG_COMPARISON_041.html)用于查看实际游戏画面。

## 从三个起点发展城市

农居负责住房和口粮，邻里中心提供基础服务，作坊兼顾材料、电力和少量生活用品。建造时从三个运营商候选中选择一家；运营商决定未来三阶段的方案槽位轨道。

选中完工建筑可升级。三棵树包含 21 个节点，越往后越专业，也需要更多投入。预览会列出新能力、失去的兼顾能力、造价、材料、施工量和新槽位。升级沿用原项目、地块、运营者、库存和住户关系。普通更换运营者、改槽和花钱随机抽方案已退出常规玩法。

建筑和升级共用城市施工能力。调整队列优先级可以决定先完成哪项；材料按实际进度消耗。缺材料不会凭空完工，花 DT 只是推进时间。

## 委托带来方案许可

任务中心同时管理一项主要委托。完成后从三份保存下来的候选中选一份，获得一次部署许可；打开页面或重载不会重抽。许可可以装进适用的建筑、组织或地区。卸下与替换不退许可，同一方案默认每个 Block 只部署一次。

地区目标仍有宜居、交付和旧区改善三个方向。达成后获得一次可以延后使用的命名权，并可继续经营当前地图。本版只开发一个 Block；District、移交、继承与多地区发展放入[展望](docs/v040/OUTLOOK.md)。

## 货运站与外部市场

把作坊沿料场方向升为货运站后，可以为粮食、材料和制成品下买卖订单。订单按实际运力逐周期成交，并受库存、仓容、资金和限价约束。电力仍在本地供应。

市场会对交易作出反应。负买价表示外部为接收过剩物资提供补贴，负卖价表示向外处置物资需要付费。成交记录与持续税收、维护收支分开查看。

## 查看与操作

地图保留原有城市图层和建筑详情。HUD 报状态，主题页看总览，再进入管理与详情。精确推进移入时间页，政策仍在同一页列出五类制度。街区填充和建筑外观随城市成长，绘制不改变库存、实体或游戏随机数。

系统时钟与城镇时间分开。手动暂停阻止自然结算和 DT 推进；查看信息与比较方案也暂停自然运行。原有键盘、鼠标和触摸布局继续保留；具体平台与输入验收见报告。

## 当前版本存档

本版保存到独立 `MET-RiverValley-040/river_valley_v5.json`。同版本可以保存、恢复和导入备份；奖励候选、施工进度和贸易订单一并保存。

**整个 pre-alpha 阶段不提供跨版本存档兼容。** 升级到格式不同的版本时开始新游戏，不做旧城市迁移或奖励补发，也不覆盖其他版本的文件。

## 源码与复现

源码仓库：[theodontino/MET-Laisheng](https://github.com/theodontino/MET-Laisheng)（私有）。

克隆后用 Godot 4.7.2 Standard 打开 `project.godot`，等待首次资源导入后运行。仓库包含游戏源码、运行资源、美术生成器、设计文档和本轮文本验收记录；`build/` 安装包与 `.godot/` 缓存不纳入 Git。运行和核心检查不需要 Blender，重新生成美术时才需要 Blender 4.5.1 与脚本所需的 Python Pillow。

完整源码、美术生成器及代表性 Blender 场景打包在 `build/MET_0.4.0_Laisheng_Source.zip`。独立解压后用 Godot 4.7.2 打开 `project.godot`。
