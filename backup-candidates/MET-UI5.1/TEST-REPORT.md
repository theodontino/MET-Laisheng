# UI5.1 实际检查结果

版本 `0.7.0-ui.5.1-local`，在本机 Unity 6000.6.5f1 / macOS Metal 上完成后台 Player 执行。最终运行退出码 0；**693/693 项检查通过，0 失败、0 原生错误，34 张 1920×1080 离屏截图**。完整原始结果在 `runtime-headless/ui5-headless-validation.json`。

## 本轮结果

- 默认字号下，概况的一个主动作及居住/供给/施工摘要同屏可见；三个里程碑和主题动作同屏可见。
- 建造页使用真实建筑目的、同一步预测和真实价格；三种运营方案在默认首屏完整可见；120% UI / 150% 字号下固定确认按钮完整可见，方案区仍可滚动。
- 任务展示源定义合并后的即时支付、保证金、资源交付、期限/目标和候选方向；接受按钮保留原命令验证，当前不足不被当作可支付承诺。
- 蓝图显示用途、领取后生效条件及真实数值；“职住一体”的关系收益已补回；内部字段和年度来源编号不占据候选正面。安装预览区分所选建筑规则与全城预测；成本/不利变化为提示色。
- 原领取、取消、重复确认、许可计数、安装/替换/卸下保护、只读预测、缓存、保存读取等回归继续通过。新增页面打开和展开对序列化游戏状态（含 RNG）不产生修改。
- 支持范围内 UI80/100/120 与独立150%字号的 HUD 几何、字体刷新、MET/1×完整渲染通过；概况、里程碑、任务、Bonus与展开详情、建造页的可见文本高度和同级控件矩形检查通过。

## 实际截图复查

主线程直接查看了最终概况、任务、里程碑、蓝图候选、安装相关页面、建造页及缩放 HUD。每组前后对照见 `comparison.html`。前图来自已保存的 UI5 完整植被采集，不使用早期漏绘树木的画面；动画采样帧可能不同，前后图用于视觉比较而非逐像素判等。

保留两次失败：`attempt1-frame-check` 有装饰边框误判重叠；`attempt2-large-text` 有两类真实大字号文字超高。最后一轮在修复后重新执行完整流程，未删掉失败历史。针对默认概况图标遮字和第三建造方案贴底，也加入了边界/首屏检查。

## 未覆盖的真实桌面验收

本轮使用 `-batchmode`、临时独立存档和实际 Button 回调，截图是世界相机与 uGUI 的离屏合成。没有启动前台游戏、发送 OS 鼠标/键盘、操作用户现有窗口或写玩家存档。

仍需真实1920×1080全屏检查：鼠标命中和快速悬停/切换、Dock动画及减弱动画体感、键盘可达、Esc关闭tooltip后焦点是否仍在有效控件、焦点进入tooltip后旧blur计时是否会隐藏它、L/Shift+L与输入归属，以及实测帧率/负载与正常退出。这些没有被上述693个程序检查替代。

本轮改善操作层级与可读性；图标、材质和3D美术的整体完成度仍与参考图有差距，不声明整个游戏UI已验收。
