# MET UI5.1 本机演示

版本 0.7.0-ui.5.1-local；Unity 6000.6.5f1；macOS Intel + Apple Silicon；ad hoc 签名，未 Apple 公证。

双击 Start Demo.command。首次复制随包真实游戏检查点，使用独立的 ~/Library/Application Support/MET Strategy HUD UI5.1 Demo 存档。请通过脚本启动；本轮验证没有启动这个常规演示，也没有改玩家存档。

右侧“下一步”根据当前城市的决定、供给、施工和发展主题给一个主动作。左下方直接选择农居、邻里中心或作坊，再点空地比较建造方案。右下方控制时间。顶栏区分资源、可用许可、任务和已记录的里程碑。城市状况先呈现一个主动作和居住、供给、施工三项摘要；里程碑把三阶段并排到同一组。任务选择先给实际代价和结果，完整管理、来源和记录仍可展开。

沿用真实游戏的奖励、蓝图领取与安装、施工及同一步现状/建成预览规则，不改模拟数值。已安装蓝图、未安装副本和待领取奖励分别显示。

同一 app 字节通过 693 项无界面程序检查，0 失败。ScreenShots 来自本机 Metal 上实际 Unity 世界及 uGUI 的离屏渲染合成；具体采集范围见 RENDER-SCOPE.json。不是桌面截图，不证明真实鼠标命中、键盘焦点、悬停等待或帧率。按用户“正在使用电脑”的要求，本轮未发送系统输入或打开前台游戏；这些实操验收暂缓。

SOURCE-CHANGES.patch 是本轮相对已交付 UI5 的局部修改。保留了原工作区其他改动；未提交、推送或发布。
