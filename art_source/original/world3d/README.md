# Hero Valley original sources

The editable Blender scenes in this directory are generated from the existing
MET building constructors and original native fern geometry. Rebuild with:

`blender --background --python-exit-code 1 --python tools/make_art040.py -- --runtime3d`

The registered runtime files live separately in `assets/world3d/`. See
`docs/living_world/ASSET_PROVENANCE.md` for provenance, project-original licensing
scope, Y-up conversion, uniform scale, and restrictions on private vendor raw.
