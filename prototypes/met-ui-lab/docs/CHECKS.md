## 复现

构建后运行 `node scripts/browser-check.mjs`。脚本需要本机已安装的 Playwright 和 Chromium；可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 的 `index.mjs` 绝对路径，默认尝试 Codex 的本地工具运行时。脚本不下载浏览器。

检查结果和完整截图写入 `test-results/`，不作为演示所需文件。交付包保留代表截图及 JSON 结果。用户仍需评价信息是否足够、阅读是否舒适、栏目与操作是否符合实际游玩习惯。

浏览器截图生成后，最后调整了大字号时图例与图层栏的间距，并让建筑详情中的 Bonus 入口带入适配方案。这两处完成了 TypeScript 与打包检查，未重新生成浏览器截图。内置浏览器随后拒绝本地 `file://` 预览；交付保留离线文件供本机浏览器直接打开。
