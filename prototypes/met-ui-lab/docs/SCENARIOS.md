# V2 阅读提示

本版左侧先打开可操作小表；下列流程中需要完整页的步骤，可用右上「详表」展开。左侧重新点击或「收回侧栏」回到日常页。任务成长路线与已完成记录位于高级详表；档案直接全屏。推荐先读 [V2 日常侧栏](V2-SIDEBARS.md)。

# 六组场景实操

从顶部 MET 标志进入系统，在「演示场景」载入预设；地图上的场景名称也可进入系统。共有六组、七个状态，终局与只读归档属于同组的两个子变体。切换场景会替换当前内存中的演示，可先保存。只读归档禁止经营操作，但仍可从系统切换、重置或载入其他演示；也可通过「独立开始新演示」离开只读状态。

以下是可执行的查看脚本和预期模型行为，不是浏览器操作已通过的验收报告。每组可独立载入，不要求按顺序完成。所有结算都需先继续时间，再明确点击「＋月」或系统页的「推进演示月份」。

## 1. 初次开拓 · `first`

1. 载入「初次开拓」，查看顶部资源提示和收支账本；首次结算尚未发生，历史回执不应伪造一笔零额结算。
2. 进入居民与服务，查看人口、就业、住房与服务来源。初始为 24 位居民、12 人就业。
3. 收起工作台，选择空地，选择农居、邻里中心或作坊，打开新建操作窗。
4. 阅读运营者、即付通货、材料／CP 需求及展开后的城市整体对比。取消应只关闭预览；确认后出现施工项目。
5. 继续时间并推进月份，再查看账本与施工。工程完工前，新建筑不应提前产生资源或服务。

也可在系统页选择「独立开始新演示」，依次填写名称、选择起源与主题。地点共用河谷底图，起源是选择记录；五种主题有实际目标与委托方向。

## 2. 日常经营 · `normal`

1. 查看默认 48 人街区，在顶部点击食物或通货，进入资源账本。
2. 选择资源，查看每座建筑与当地居民的贡献；点击来源名称打开详情抽屉。
3. 在同一列表使用「定位」返回地图，再使用「返回原列表」恢复工作区。观察页签、筛选、排序与滚动位置的保留。
4. 进入市场，创建一笔小额买单。可用通货立即扣除预留款，资源不会立即到货；撤单应退回预留款。
5. 再次创建订单，继续并推进一个月。订单应变为已成交；实际交易回执与当前经营预估分别查看。
6. 在地图切换医疗、就业、电力等图层，用 `L`／`Shift+L` 循环，单独按 Shift 切换数值标签。使用地图缩放按钮比较视图；显示比例与文字大小在系统页独立调整。

「在线交易」在本原型中是本地模拟订单，不连接在线市场。报价固定，买卖同价，只有明确推进月份才成交。

## 3. 短缺处理 · `shortage`

1. 载入短缺场景，查看右侧口粮与医疗提示。两座农居和一处邻里中心停运，另有暂停的新建项目；低库存与停运是具体原因。
2. 从提示进入账本或居民列表，打开供应来源，区分服务容量、住区实际满足和当地可达度。
3. 在停运建筑详情恢复运营，再查看顶部净流、服务汇总和来源行是否同步改变。
4. 也可使用市场购买口粮、实施社区餐桌政策，或调整施工；先阅读即时费用与后续月流。
5. 继续时间并推进月份，查看库存、连续达标月份与结算回执。经营预估不等于此前已经到账的收益。

## 4. 建设管理 · `construction`

1. 载入建设场景，在施工页查看一项新建与一项农居升级。
2. 打开地块详情，比较新建尚无产出与原建筑升级期间按 65% 运营的区别。
3. 把优先项目设置为「高 · 1」，暂停或恢复另一项目，观察预计施工分配与材料需求。
4. 打开招募工程队操作窗。第一队 60 通货，下一队按 `60 × 2^当前在岗队数` 报价；每队增加 4 CP／月，持续一次演示月。
5. 确认雇佣后推进一个月，查看工程进度、材料消耗、队伍到期与报价变化。无项目也会到期，不能提前解约退款。
6. 从已建建筑发起升级，选择专业化并展开同一步对比。T2 次要能力减半，T3 对应次要能力可归零；住房减少不会删除原有居民。

有效 CP 受供电约束，预计分配还受材料限制；「城市工程预留」在该演示夹具中为零，不是队列剩余工作量。

## 5. 奖励与研究 · `reward`

1. 进入任务与成长，查看已经明确完成的第 1 阶段与待领取奖励。
2. 打开奖励窗，只选择方案不应入库；点击领取后获得一份副本，再选择留在任务或前往 Bonus。
3. 在 Bonus 工作台依次选择副本、适配建筑、同类型槽位，阅读实际变化项。
4. 确认安装后查看库存、副本部署数、建筑槽位与城市汇总。替换会消耗新副本，并失去旧副本。
5. 研究已解锁蓝图，支付 80 通货与 20 材料；已安装副本随蓝图升级增强，最高 3 级。
6. 切换主题，查看实际增加的主题目标及未接取委托变化。已接取委托保持原内容；变更主题重新累计连续达标月份。
7. 接受委托后再交付，检查完整物资扣除、通货到账及 Bonus 选择资格。超过截止月份不能接取或交付。

普通阶段也需所有条件与连续保持月份满足后，明确点击完成，才产生阶段记录和奖励。当前达标不自动伪造未来完成记录。

## 6. 终局与档案 · `ending`／`readonly`

**终局命名：**载入 `ending`，查看 DT 为零、三个阶段已完成；在任务页确认街区名称，选择现有建筑作纪念地标，再保存终局记录。到档案查看记录及其来源。该操作保留当前经营状态，仍可用 1 倍速建设和推进月份；1 倍速不消耗 DT。

**只读归档：**单独载入 `readonly`。浏览账本、建筑、Bonus 与档案，确认经营命令不可用。该状态不是点击保存终局记录后自动产生的结果。使用系统页或档案页的「独立开始新演示」建立新街区。

DT 为零本身不代表三个阶段已完成。模型要求 DT 为零且三个阶段全部完成，才允许终局命名与地标选择；不足资格时命令会给出原因。旧委托在这两个晚期夹具中已过期。
