# V2：地图旁的日常小表

V2 保留 V1 的完整工作区，改为「高级详表」。日常入口使用独立组织的小表，宽约 640–700；地块面板约 640。高级详表展开后占满顶栏和左侧导航之外的可用工作区域。原有方案比较仍为居中独立窗口。

## 这次的分工

| 栏目 | 在侧栏直接完成 | 何时展开高级详表 |
| --- | --- | --- |
| 地块／建筑 | 图像与身份、人口就业四格、净收入与服务环境并排、槽位；新建、运营、升级、施工控制 | 建筑原始产出与来源继续作为对象详情 |
| 居民与服务 | 住房就业小矩阵、四种服务表、住区清单；点服务同时切地图图层，点住区展开提供者；迁入与生活用品 | 住区与服务容量的完整横向比较、全部提供者追溯 |
| 资源与财政 | 资源库存和月净额、当前资源来源；市场快速下单／撤单；政策当前与候选比较并应用 | 完整订单与回执、账本、所有政策比较 |
| 施工 | CP 构成、供电和材料限制、项目进度／剩余／优先级／暂停；招募临时队 | 跨项目排程、能力和队伍完整信息 |
| 任务与成长 | 当前目标的当前值／目标／缺口同表，做法在行内展开；接取、交付、阶段确认、奖励领取 | 三阶段成长路线、完成记录、终局命名与地标 |
| Bonus | 副本清单、目标建筑／槽位、仅变化的比较；直接安装、明确替换确认 | 蓝图研究、完整来源与多目标比较 |
| 档案 | 直接打开完整页，无小表中转 | 分类、记录与正文同时显示 |
| MET | 直接打开设置页 | 场景、存读档、显示和时间说明 |

小表会根据内容收紧高度；内容多时在正文内滚动。减少留白不靠缩小字号，仍保留独立的 UI 比例和文字大小。

## 导航行为

- 左侧切换始终打开该栏日常小表；保留栏目选择与草稿。档案和系统有各自的直接入口。
- 小表右上「详表」展开现有工作区；底部的专题详表按钮可指定具体页签。展开不会清空小表的滚动位置。
- 详表右上「收回侧栏」或 Esc 返回小表；两种展示形式分别保存滚动位置，筛选与选中对象共用。
- 右上关闭收起整个栏目；不再同时摆放模糊的两个返回按钮。
- 侧栏打开时地图仍可选地块。选择／定位后，地图提供明确返回原栏目入口。
- 侧栏里的服务筛选直接改变地图对应图层，L／Shift+L 与 Shift 数值开关仍可使用。输入框和操作窗口拥有键盘。
- 任务里的“处理”指向精确服务或资源，而不是沿用上一轮查看的任意筛选。
- 从已安装 Bonus 槽进入时，即使该方案库存为零，也保留指定方案、建筑与槽位。安装成功后留在当前方案查看结果。

## 建议先看这几处

打开即为「平稳经营 · 居民与服务」小表。点击医疗，再点一处住区展开来源；展开右上详表，再收回，对比两种阅读方式。

切到财政，在同一侧栏切换收支、市场和政策。建立一张材料订单，撤销后检查通货返还。施工场景可以从 MET → 演示场景切换，直接调整队列。

在「奖励与蓝图」场景领取奖励，再到 Bonus 小表选目标和槽位安装。完成操作后去档案查看记录。

本版未增加玩法与数值规则，也没有把界面移植到 Unity。数值和比较继续使用自带演示街区。
