# V3 · 地图地块与图形侧栏

## 两个独立区域

- 地块是地图对象。默认打开地图并选中邻里中心，地块面板位于左下（逻辑坐标 left 14 / bottom 18，宽 640、高度最多 520）。顶部导航的实际下沿限制面板高度，内容内部滚动，标题和行动区固定。
- 居民、财政、施工等是全局工作区，继续从左侧导航旁展开。打开全局工作区暂时收起地块；关闭后恢复原选中地块和该地块滚动位置。选中地图其他地块不把地块变成全局栏目。
- 图层与图例从逻辑横坐标 680 起排列，和地块留出间隔；右下时间控制仍独立。UI 及字体变化继续使用原设置，不缩小正文。
- 来源检查仍可在全局栏目内用附属抽屉；定位会回到地图地块，保留返回原工作区入口。高级详表和独立操作窗口继续使用原布局。

## 图形与口径

| 内容 | 表达 | 数值口径 |
| --- | --- | --- |
| 住房入住 | 容量条 + 人数 | 居住人口 / 有效住房容量 |
| 居民就业 | 比例条 + 人数 | 已就业居民 / 居民总数，不除以岗位 |
| 岗位使用 | 容量条 + 岗位数 | 已使用岗位 / 本地岗位 |
| 服务满足 | 四格图标 + 满足条 | 当前比例 / 100%，保留不足住区筛选 |
| 资源库存 | 图标 + 库存 + 月净额 | 不编造仓容量，不把库存画成任意百分比 |
| 收支来源 | 共用零轴的双向条 | 消耗左、产出右；同图同刻度，末端精确数字 |
| 电力 | 需求 / 供给容量条 | 超供给时以缺口色标记，真实数字仍显示 |
| 建造力 | 使用条 + 来源堆叠 | 使用 / 有效能力；构成带单独标明原始基础、建筑、临时队 |
| 材料备齐 | 队列需求覆盖条 | 已备齐 / 所需；额外库存单独说明，不画成超量警报 |
| 工程、临时队 | 完工或剩余时间条 | CP 完成量、合同剩余月数 |
| 任务 | 条件进度 + 做法展开 | 当前 / 目标；污染明确标成上限，达成型目标超过目标不显示容量警报 |
| Bonus | 带图标的库存选项 | 副本数量保留数字，变化比较保留对齐表格 |

容量为零显示“暂无容量”；可用容量存在而尚未入住显示 0 / 容量。超容量不会把真实值改成最大值，只限制条的绘制宽度。所有页面继续共用原演示状态，未改演示模型结算规则。

## 直接体验

1. 打开离线 HTML：左下查看邻里中心，切换地图其他地块；空地仍可选基础建筑。
2. 打开居民栏目：查看入住和就业条，点击医疗或教育筛选不足住区，定位后回到左下地块。
3. 打开资源与财政：点击资源图标切换贡献图；选择电力查看供需方向。市场下单及政策操作保持可用。
4. 切换施工场景：查看施工进度、材料覆盖、CP 构成，调整优先级或暂停，招募临时队。
5. 查看任务条件进度、展开如何达成；领取 Bonus 后在图标库存中选目标安装。
6. 任一侧栏右上“详表”进入保留的完整表格；“收回侧栏”或 Esc 返回。
